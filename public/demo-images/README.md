# 演示图片来源

这些 PNG 为本项目自行绘制的几何风景，不含真实 B站内容或第三方图片。生成源码：`scripts/generate-demo-images.mjs`。可在 nvm 指定的 Node 下执行 `pnpm exec node scripts/generate-demo-images.mjs` 重建。

- 1–10：实际缩略图 240×180，预览图 1200×900。
- 11：实际缩略图 240×120，预览图 1200×600；读取结果故意缺失尺寸，用于验证加载后处理实际比例。
- 12：实际缩略图 90×240，预览图 600×1600。
- 缩略与预览是分别生成的不同尺寸文件，并非用 CSS 缩小同一份原图。
- `.v1.png` 表示素材版本；URL 中的签名形式参数仅为虚构边界样例，不含凭据。
- 图片网络失败由测试在浏览器资源边界确定性触发，正常数据不使用故意失效 URL。
