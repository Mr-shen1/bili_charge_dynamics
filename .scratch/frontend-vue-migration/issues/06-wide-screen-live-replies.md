# 06: 宽屏预览回复并按实时页码阅读

**What to build:** 宽屏用户可从最多 3 条回复预览展开、实时翻页、收起，并在返回详情时恢复回复阅读意图而不是冻结页内容。

**Blocked by:** 05 — 阅读一级评论、切换排序并恢复讨论进度。

**Status:** done

**差异处理硬规则：既有文档、测试或历史验收描述与现有代码逻辑冲突时，一律以现有代码逻辑为准。** 按已记录源码基线核实后修正文档和测试，不为迎合旧描述恢复、删除或改变现有业务行为；后续发现同类差异也按此处理，无需重复请求裁决。明确授权的 Vue、Element Plus、新视觉及图片放宽属于目标变化，不被旧实现反向覆盖。代码基线不等于已经运行验收通过。

- [x] 预览最多 3 条使用 cursor；展开使用 page、固定 limit=10 且与 cursor 互斥，请求 no-store。25 条本地回复按 10/10/5 替换当前页，不恢复累计追加。
- [x] 页码为正的安全整数；每次展开重读第 1 页，翻页及同页重读发真实请求，不使用页缓存跳过读取。
- [x] 收起取消在途请求、定位根评论开头并保存收起状态及 page=1；再次展开重新首读。
- [x] 详情历史恢复保存的预览、expanded、page 和文字状态；已展开回复按保存页码实时重读，不复用冻结页结果。
- [x] 根据本地 count/localReplyCount 计算末页；数量缩减导致越界空页时重读有效末页，不以 nextCursor=null 判断没有其他页，不承诺实时页间冻结。
- [x] 保留时间正序、作者身份和实际超过 6 行折叠；仅嵌套回复且目标昵称可用时展示“回复 X:”，直接回根不重复目标，渲染时剥离来源重复前缀。
- [x] 局部失败仅影响对应回复区域且保留已有内容；仅 422 CURSOR_INVALID 映射 invalid-cursor，404/422 INVALID_INPUT 为普通可重试 error，取消优先。
- [x] 防重、收起取消、切换排序/访问和忽略取消的迟到成功/失败/完成回调均有页面行为覆盖；根评论与回复的请求保护分别有效。
- [x] 真实浏览器验证收起定位、详情返回恢复及折叠布局；生产 Adapter 测试仅替换传输并保留真实映射，不删除后端兼容 cursor 协议。
