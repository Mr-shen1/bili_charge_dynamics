# 02: 在 Vue 中浏览全部及单 UP 归档

**What to build:** 用户能通过首页和单 UP 页面切换阅读范围、阅读动态并连续加载归档；装配、主题、类型检查与测试随这条真实读取路径接入。

**Blocked by:** 01 — 验证原生图片预览与浏览器历史的组合行为。

**Status:** ready-for-agent

**差异处理硬规则：既有文档、测试或历史验收描述与现有代码逻辑冲突时，一律以现有代码逻辑为准。** 按已记录源码基线核实后修正文档和测试，不为迎合旧描述恢复、删除或改变现有业务行为；后续发现同类差异也按此处理，无需重复请求裁决。明确授权的 Vue、Element Plus、新视觉及图片放宽属于目标变化，不被旧实现反向覆盖。代码基线不等于已经运行验收通过。

- [ ] 默认真实 API，独立 mock 与开发故障装配隔离；展示层消费既有契约，不解析原始 DTO、推导 cursor 或拼接 OSS 地址，不新增业务 API。
- [ ] Vue 模板与 TypeScript 类型检查可运行，应用会话由根部创建并高于路由页面存活，测试可创建独立实例；不引入跨测试可变单例、Pinia 或请求缓存框架。
- [ ] 默认全部归档，UP 选择条可切换全部/单 UP；25 条动态按 10/10/5 追加，稳定排序、冻结 cursor 语义、去重、同批重试及列表结束提示正确。
- [ ] scope、cursor、请求身份隔离；覆盖快速切换、重复点击、cursor 失效及忽略取消的迟到成功/失败/完成回调，不串内容、不清掉新加载态。
- [ ] 区分未知 UP、已知 UP 空归档和请求失败；停止监控或删除配置后的已有归档仍可访问。
- [ ] 作者、发布时间、来源/本地计数及零/未知语义正确；安全显示换行、emoji、长 URL 和恶意 HTML，不恢复阅读页编辑时间或归档统计面板。
- [ ] 列表正文实际超过 6 行才折叠，宽度变化后判断正确；文字不撑宽页面，UP 条仅内部横滚。
- [ ] 通用控件采用 Element Plus，主题沿用浅青背景、白卡、青蓝选中与粉色作者信息方向，不锁定旧像素值或建立平行基础组件库。
- [ ] 随本票交付页面公开行为、确定性规则及必要 Adapter 契约测试；四视口、键盘及错误状态有验证，普通归档读取不触发采集或上传。

依据本工作规格、行为基线差异及已确认迁移方案。未经授权改变的业务行为按固定代码基线保留，漂移测试按代码修正；明确授权的技术、视觉和图片变化除外。本票完成列表读取路径，详情进入/返回由 03、真实页面图片接入由 04 交付，不据本票宣称完整迁移完成。保留后端、数据库和采集行为，不操作当前运行实例或部署。
