# 07: 窄屏通过 UP 回复预览进入独立楼中楼

**What to build:** 手机用户从根评论的 UP 回复预览或数量入口进入独立楼中楼、实时翻页，再返回原详情继续阅读。

**Blocked by:** 05 — 阅读一级评论、切换排序并恢复讨论进度。

**顺手项：** [retro-06](../retro-06.md) 第 3 条（读取层 `catch` 保留异常原因）与第 4 条（交付状态文档收敛为单一来源）。

**Status:** done

**差异处理硬规则：既有文档、测试或历史验收描述与现有代码逻辑冲突时，一律以现有代码逻辑为准。** 按已记录源码基线核实后修正文档和测试，不为迎合旧描述恢复、删除或改变现有业务行为；后续发现同类差异也按此处理，无需重复请求裁决。明确授权的 Vue、Element Plus、新视觉及图片放宽属于目标变化，不被旧实现反向覆盖。代码基线不等于已经运行验收通过。

- [x] 保留窄屏阈值 640px，无法判定时按宽屏；仅正来源回复数展示预览/入口，零或未知不展示，本地零但来源正仍可进入。
- [x] 有合法作者摘要时展示该动态作者在此楼最早一条回复，无作者回复时仅显示数量入口；目标文案按可用 replyTo 展示并剥离重复来源前缀。
- [x] 独立楼中楼路由可直达和刷新；每次重新挂载（包括历史重新进入）均从 page 1 和顶部开始，不新增自身阅读快照、持久化历史或页码记忆。
- [x] 每页使用 page、固定 limit=10、no-store 且不带 cursor；响应提供 root，按本地 count/localReplyCount 分页，越界空页重读有效末页，不承诺跨页冻结。
- [x] 页头数量按来源数→本地 count→items 数回退；额外读取动态仅用于 UP 标识，辅助失败不阻断主读取。
- [x] 根评论、回复正文及窄屏 UP 摘要直接安全显示，不新增 6 行折叠或图片；条件化回复目标语义正确。
- [x] 有有效详情来源时返回并恢复详情，无来源则 replace 到对应动态详情；分页器收起同返回。
- [x] 缺失根保持普通可重试读取错误，不新增详情式 not-found；取消优先，仅 CURSOR_INVALID 映射 invalid-cursor，不把生产不可达空 root 分支扩成需求。
- [x] 页面行为、Adapter 和真实浏览器测试覆盖正/零/未知来源数、有无作者预览、直达、翻页、返回、重新挂载首屏、迟到回调及与详情快照的隔离。
