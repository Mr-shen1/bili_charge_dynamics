# 08: 查看一级评论图片且不串组、不丢讨论进度

**What to build:** 用户可查看任意一级评论的完整图片组，并回到原评论位置继续阅读；动态与不同评论的图片互不混入。

**Blocked by:** 04 — 在动态列表和详情查看完整图片组；05 — 阅读一级评论、切换排序并恢复讨论进度。

**Status:** ready-for-agent

**差异处理硬规则：既有文档、测试或历史验收描述与现有代码逻辑冲突时，一律以现有代码逻辑为准。** 按已记录源码基线核实后修正文档和测试，不为迎合旧描述恢复、删除或改变现有业务行为；后续发现同类差异也按此处理，无需重复请求裁决。明确授权的 Vue、Element Plus、新视觉及图片放宽属于目标变化，不被旧实现反向覆盖。代码基线不等于已经运行验收通过。

- [ ] 复用实际页面已接入的原生图片连接能力；动态与各根评论的 owner 隔离，组内顺序、所点索引正确，缩略显示数量不截断完整组。
- [ ] 覆盖单图、多图、长图及成功/浏览器失败/未上传/无效地址混合组；异常不阻断切换关闭，可重试项仅重试既有公开 URL。
- [ ] 同 URL 打开不重挂载底层详情，切图不增加历史；按钮/键盘关闭及后退不二次回退，有效会话前进恢复对应预览。
- [ ] 预览不重置排序、已加载评论或文字展开；关闭恢复位置和焦点，覆盖排序后原触发元素消失的合理后备。
- [ ] 实际评论区域重验焦点约束、底层滚动锁、冷缓存按需请求及四视口可操作性，不仅复用动态图片测试结果。
- [ ] 不增加回复图片或独立楼中楼根评论图片，不触发采集/上传，不回退来源业务图。
- [ ] 随票交付页面行为、传输映射及真实浏览器历史/布局/网络证据，保持评论排序与阅读快照的组合保护。

## 依据与执行边界

依据本工作规格、行为基线差异及已确认迁移方案。图片展示和原生交互按明确例外调整，完整性、owner、历史及恢复底线保留。04 与 05 分别提供真实图片连接能力及评论宿主，均为本票的直接阻塞。不执行部署。
