## Comments

已完成并留证：[05 一级评论阅读证据](../evidence/05-root-comment-reading.md)。
`pnpm typecheck`、`pnpm test`（89）、`pnpm test:e2e`（126 passed / 10 skipped）、`pnpm test:e2e:production`（3 passed / 3 skipped）
与构建隔离/数据副本检查均通过。默认装配仍连真实 API，mock/fault 受控归档只在显式 mode 出现。

实现要点：`CommentSnapshot`（排序 + 已读批次 cursor + 文字展开）进入详情访问快照并按 `pageEntryId` 隔离；
`navigation.openDetail(id, 'comments')` 记录入口意图，历史恢复不消费该意图；`useCommentsRead` 复用列表读取的
cursor 追加、同批重试、结束停止与请求身份校验。排序切换整体重挂载评论列表子树（DOM 与实例一起销毁），
因此目标排序首批、文字展开以及后续回复展开状态都被重置；快速切换只接受最后一次选择的成功、失败与异常。

code-review 前的实跑修正：切换排序时旧批次卸载会把页面高度缩短、滚动被浏览器夹紧，导致评论区顶部停在下方
（实测 296px）；改为切换后新批次落下再定位一次，并在用户主动滚动/触摸/按键后放弃该次定位。
评论入口同样只在首批落下后定位，且用户已操作时不抢回。code-review 另修正：连续切换排序时旧的用户操作监听未解除，
现统一走 `app/readingPosition.ts` 的 `onUserScroll`，重挂前先解除上一组；e2e 改为使用两个项目各自的真实视口并补四宽度无横溢检查。
