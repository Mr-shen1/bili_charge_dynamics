**Blocked by:** 无（可立即开始）。

**Status:** done

### 后续体验诉求（已裁决：接受现状）

真机通过后用户提出三条交互优化，核查 Element Plus 2.14.7 公开能力后确认均不在库内（证据第 9 节）：

1. 拖动到图片边界应停住，不能拖出屏幕；
2. 放大倍数未达到上下左右边界时不可拖动；
3. 左右切图应有跟手过渡（滑动过程中就显示下一张）。

三条都需要自建预览渲染（双图轨道 + offset clamp），与规格“不重写缩放、旋转和手势引擎”“不恢复整套自研预览”冲突。
**用户已裁决：接受现状，记为已知限制，不阻塞本票、后续票据与统一上线门槛。**
