# 04: 在动态列表和详情查看完整图片组

**What to build:** 用户在真实动态列表和详情中从缩略图打开原生预览，查看完整图片组并回到原阅读位置。

**Blocked by:** 03 — 进入动态详情并恢复列表与详情阅读位置。

**Status:** ready-for-agent

**差异处理硬规则：既有文档、测试或历史验收描述与现有代码逻辑冲突时，一律以现有代码逻辑为准。** 按已记录源码基线核实后修正文档和测试，不为迎合旧描述恢复、删除或改变现有业务行为；后续发现同类差异也按此处理，无需重复请求裁决。明确授权的 Vue、Element Plus、新视觉及图片放宽属于目标变化，不被旧实现反向覆盖。代码基线不等于已经运行验收通过。

- [ ] 使用 01 已验证的原生图片方案及唯一导航协调器接入实际归档数据，不引入第二套预览、图库或历史协调实现。
- [ ] 覆盖纯图、单图、4/9/超过 9 图及长图；数量是夹具而非旧布局约束。图片不变形，完整组可达，顺序、owner 和所点索引正确。
- [ ] 点击图片不误触卡片导航；同 URL 预览不重挂载底层列表/详情，切图不新增历史条目。
- [ ] 关闭及历史后退/前进恢复对应图片、底层内容、位置和合理焦点，不多退一级、不重置阅读状态；覆盖重复开关和触发器消失。
- [ ] 区分上传 pending/failed、无效公开 URL 与浏览器加载失败；异常图片仍可跳过/关闭，局部重试只访问既有公开地址，不触发采集/上传或回退来源业务图。
- [ ] 在实际页面用冷缓存和可区分 URL 重验缩略懒加载、预览按需请求，再覆盖生产共用 URL；不以 01 的受控结果替代集成证据。
- [ ] 真实浏览器覆盖焦点、滚动、四视口和工具栏可达；正常图片及失败图片组合不破坏阅读恢复。
- [ ] 页面行为和 Adapter 边界测试保留公开行为保护，不绑定 Element Plus 私有实现；不自动启用下载、自动轮播等范围外能力。

## 依据与执行边界

依据本工作规格、行为基线差异及已确认迁移方案。原生布局与交互可按已授权图片例外调整，完整性、手机可用性、导航和恢复不得放宽。01 的门槛通过不等于本票集成通过；不修改 API 或操作当前运行实例。
