# 03: 进入动态详情并恢复列表与详情阅读位置

**What to build:** 用户从动态卡片进入详情，返回正确的全部或单 UP 来源列表继续阅读；同一动态的不同访问拥有各自阅读状态。

**Blocked by:** 02 — 在 Vue 中浏览全部及单 UP 归档。

**Status:** done

**差异处理硬规则：既有文档、测试或历史验收描述与现有代码逻辑冲突时，一律以现有代码逻辑为准。** 按已记录源码基线核实后修正文档和测试，不为迎合旧描述恢复、删除或改变现有业务行为；后续发现同类差异也按此处理，无需重复请求裁决。明确授权的 Vue、Element Plus、新视觉及图片放宽属于目标变化，不被旧实现反向覆盖。代码基线不等于已经运行验收通过。

- [x] 卡片点击或键盘激活进入详情顶部，文字选择、正文折叠及内嵌操作不误触导航；详情动态正文全文显示。
- [x] 详情直达、刷新、不存在动态及请求失败分别处理；无有效列表来源时返回首页。
- [x] 返回恢复来源列表已加载批次、正文展开及位置；同一动态的多次访问互不覆盖，不以动态 ID 作为唯一快照身份。
- [x] 内容实体、访问快照和请求运行态分开；会话跨页面存活，主动进入顶部的意图优先于旧位置，不新增持久化阅读历史或跨标签页同步。
- [x] 恢复先还原内容和展开状态，再按稳定锚点定位；慢布局、缺失锚点与迟到任务有界回退，不无限等图；用户主动滚动后停止纠正。
- [x] 唯一导航协调器负责位置恢复，不与路由自动滚动或页面局部历史逻辑竞争；不照搬 React Router 内部 key/state API。
- [x] 离开未完成读取再返回可继续读取，不遗留永久加载态；旧成功、失败和完成回调不能改写新访问。
- [x] 用页面行为测试和真实浏览器覆盖来源范围、同动态多访问、主动进入、后退/前进及布局恢复；安全文本、时间/计数及阅读信息裁剪保持基线。
