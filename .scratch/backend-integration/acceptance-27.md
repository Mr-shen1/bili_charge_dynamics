## 可观察交付

- `Collector.discover_once(uid)` 按当前启用 recent 配置跨页累积 N 个唯一合格字符串 ID；普通项、重复项不占名额，够 N 停止，真实耗尽可不足 N。
- `GET /api/manage/ups/{uid}/discovery` 返回当前配置、active、status、本轮 attempt、最近 trusted_result、retryable/incomplete；只读 SQLite，不请求上游。默认 N=10、多 UP 各自独立，可处理 7 UP / N=101，不添加 5 UP / 100 目标上限。
- 本轮进行中/失败部分 ID 不替换旧可信结果。HTTP/业务/网络/JSON/候选/分页/循环游标错误保持旧结果，错误与部分进度重开仍可见。首次失败无可信结果与真实耗尽成功空分开。
- 同一固定 15 秒节拍独立轮转 recent UP，默认 2 个发现名额，不占指定目标检查/归档执行名额。慢发现同 UP 忙即跳过，其他 UP 下一固定节拍可重试，指定检查与归档 HTTP 仍可推进。
- 停用/切模式/改 N/删配置在短事务内失效在途令牌；不再请求下一页或提交旧结果。新 N 可领取，旧返回不覆盖新成功。删除配置保留身份与发现历史。
- 任务取消保留 running；API 重开不恢复在途领取。取得采集锁的 Collector 重建恢复为 `DISCOVERY_INTERRUPTED`，后续固定节拍从首屏重试；无新来源信号也能重试。
- schema v12 原子迁移；已有 v11 配置、归档与 pending 检查经 HTTP 重开保持。修正旧 v9/v10 构造夹具，降版本时移除 v12 表，避免虚假的旧数据库同时包含新表。真实旧版本迁移失败/回滚及未来 v13 拒绝仍有覆盖。

## 未验证

- 没有请求真实 B站、读取 Cookie/OSS 凭据或操作云。原脚本使用 WBI；当前生产匿名请求不增加 WBI/Cookie/绕过，拒绝如实失败。
- 静态协议、虚构多页和历史首屏不证明当前匿名多页、真实全量、并发来源移动不漏项或长期稳定性；置顶按 feed 顺序保留，不声称发布时间严格降序。这些归 #34 限定授权验证。
- 重启测试是实际持久文件、API 关闭重开与 Collector 任务重建/受控取消，不冒称硬断电或本票实测生产进程长期运行。
- 本票未运行浏览器 E2E、正式设备、部署或性能/持续规模验收；前端只做既有单元/类型回归。#28 窗口及后续生命周期/全媒体联动仍未交付。
