## 核验标准

- [ ] 近期/指定模式切换、停用 UP、删除 UP 监控配置/指定目标及窗口移出后不再发起该目标的新检查或领取新同步；指定集合与近期互斥，重新纳入可继续，目标选择不限制内容类型。
- [ ] 在检查进行中、同步等待/执行中及提交前后执行上述配置变化，按细化并测试的工作归属/提交语义收口：不把旧工作挂到新配置或错误 UP、不吞新工作、不将已停止目标偷偷恢复调度。
- [ ] 允许正确保存已取得的可读结果，但不自动删除归档或丢失持久未完成工作；停用阶段不继续新监控，重新启用/纳入后可恢复应有工作。幂等、取消及版本策略通过公开结果验证，不仅断言内部标志。
- [ ] 保存 UP 身份、正文、评论、回复以及动态图/一级评论图的 owner、顺序、公开 URL 和状态；上游消失/拒绝/失败不覆盖旧成功内容，删除配置不级联删任何归档，不自动回收媒体腾空间。
- [ ] 有旧归档的停止/删配置 UP 仍在顶部选择条，全部与单 UP 列表、详情、评论/回复和图片均可访问；不只依赖启用名单，也不需要用户保存旧详情 URL 才找到内容，scope/分页/历史快照不串。
- [ ] 重启单 API/采集进程并重开实际 SQLite 后配置启停/模式/目标正确，启用目标恢复固定检查，停用/已移除目标不被恢复为监控；observed、分项 checkpoint 和待处理仍在，旧完成不清较新观察。
- [ ] 管理 UI/HTTP 能区分未检查、可信检查无变化、同步中、部分完成和失败，显示最近检查、最近实际成功及具体未完成分项/脱敏错误；未检查不造时间，检查或一项成功不冒充整条完成。
- [ ] 组合测试可信 HTML 编辑时间变化 → 整条内容公开同步 → 正文与动态图变化 → 模拟 OSS → 实际归档 API/页面；动态媒体独立失败可重试，无新编辑信号仍恢复，不回退 B站业务图、不改用内容比对触发。
- [ ] 组合测试来源评论总数变化 → 根回复必要分页 → 一级评论图更新/上传 → API/页面；评论文本完成不等待图片完成，媒体失败不重置评论 checkpoint，纯图评论和不同 owner 预览仍正确，不扩展回复图。
- [ ] 正文受限或编辑信号不可用不阻断实际可读根回复，计数/页/图失败不归零、不清旧数据；新旧观察交错、失败无新信号重试、重复提交及重启恢复在组合路径均有证据。
- [ ] 慢检查/同步/上传时配置变更和归档读取仍能完成，固定 15 秒忙检查跳过不叠加、慢同步不阻断新检查；真实 SQLite 验证读写协调，网络不置于长事务，不许诺私有锁实现或容量阈值。
- [ ] 穿透“管理 UID/模式/目标 → fixture 检查同步 → 实际 SQLite → HTTP/生产 Adapter → 列表/详情/评论图 → 返回恢复”，保留原身份、读取、导航、焦点及局部故障测试，无查看详情按钮/转发/独立评论页/凭据 UI。

## 测试入口与实施边界

本票是 T1–T3 的跨模块整合：受控时钟、虚构 HTML/JSON、可阻塞/失败 I/O 与模拟 OSS，经真实临时 SQLite、公开 HTTP 状态和浏览器操作观察。使用虚构秘密标记核查 UI/API/诊断脱敏，不读取凭据、不请求真实上游；全历史动态补扫和新的评论截断/校准机制均排除。

前序各票已负责其范围的启停、数据保留和幂等，本票不是首次补这些正确性，而是验证完整组合及在途竞态并修正整合缺口。分页协议、工作归属与状态聚合在已定语义内细化并配套测试，实施遵循本次细化后的子票依赖，不静默增加无关阻塞。正式双进程交付、Nginx 与持续运行/真机证据由 #31–#34 执行并在汇总票 12 收口。
