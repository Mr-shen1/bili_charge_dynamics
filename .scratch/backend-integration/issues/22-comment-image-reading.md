# 22: 纯图评论与独立图片组预览

**What to build:** 详情评论区通过生产 Adapter 显示 #21 评论图，并复用 #20 预览/历史能力，让每条评论拥有独立图片组和恢复位置。

**Parent:** [07](07-comment-images.md)

**Blocked by:** [16](16-root-comment-reading.md)、[20](20-dynamic-image-reading.md)、[21](21-comment-media-archive.md)

**Status:** ready-for-agent

## 依据与交付边界

- [规格](../spec.md)：故事 22–27、32、33、35、59、62、63；I7、I9–I11；T1、T2。
- [SRS](../../../docs/product/SRS.md)：FR-08–FR-12、DR-01、DR-03、NFR-02、NFR-03；AC-09–AC-12、AC-14–AC-17、AC-30 的评论图片阅读部分。
- 遵守[共同交付要求](../implementation-plan.md#所有执行子票的共同交付要求)。#20 是明确的预览复用依赖，#21 是媒体数据依赖，不把动态图预览尚未完成隐藏为实现假设。
- 无回复图、独立评论页、真实写回、下载或自由缩放；不改气泡为真实评论缩略图，不另造历史协调器。

## 核验标准

- [ ] 生产 Adapter 在真实评论区保留图片顺序与状态；纯图评论不显示“暂无评论内容”，有文无图不留图区，两者都空才显示兜底，未上传仍表达其有图片但尚未完成。
- [ ] 单图、四图、其他多图、超过九图不变形或丢图；遵守适用九格规则，详情可访问所有缩略/预览，合理尺寸占位不严重扰动阅读位置。
- [ ] 点击即打开该评论该图片，owner 类型+评论 ID+组内图片标识正确；张数与切换只在当前评论，不串动态图、另一评论或回复。
- [ ] 复用键盘/Esc、横滑、长图完整/适宽、首尾不循环、单图无切换；纵向不滚底层、不误切，切图重置纵向位置，坏图可重试/切走/关闭。
- [ ] 后退先关预览、前进恢复原评论组；关闭回原评论位置/触发焦点或后备。反复切组、排序后触发处卸载、刷新遗留标记都不多退或循环。
- [ ] 上传失败和浏览器加载失败提示/重试语义不同；公开 URL 直取无回退，缩略懒加载、预览按需，打开一图不下载整组原图。四宽度、长昵称/长图、触控与键盘焦点合格。

## 测试与完成证据

T1 经生产 Adapter、可控图片服务和浏览器验证两个评论组+动态图组隔离、纯图评论、故障、排序/历史/焦点；至少一条实际 T2 HTTP 联测。与 #21 核对父 #07 原清单；保留动态图预览回归，真机结论留给 #33。
