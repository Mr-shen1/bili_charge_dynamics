## 复刻范围与不可改变的边界

- 复刻保留阅读区域的结构与视觉：内容主栏与页面留白、选择条、卡片、头像／作者／时间排列、字号行高、文字颜色、间距、圆角、分隔、图标、评论入口、图片容器、评论排序及回复缩进。不能以“颜色类似”或“按钮都能用”作为交付。
- 一比一是上述区域的视觉对齐，不是恢复 B站整站。仍不增加复杂两侧导航、个人主页、转发、视频、真实点赞／评论发布、关注、榜单、推荐、购买解锁或会员能力；裁剪区域不留空占位。
- 保留全部／单 UP scope、字符串 ID、绝对北京时间、分钟编辑精度、详情全文、六行折叠、分页和来源／本地数量区别。接口及管理中的未知／失败／部分完成不可美化成成功。2026-10-14 用户预览后取消阅读卡片的整块归档信息（编辑时间、来源／本地统计及归档分项状态），不折叠也不新增替代提示；保留接口真值、管理状态和独立读取／逐图／评论回复的错误反馈。
- 动态及评论图片仍保比例、按已有 owner 分组、使用后端公开归档 URL，不回退 B站业务图、不新增图片变体／CDN／下载策略。保留预览、长图、焦点和历史恢复。
- `/manage` 纳入本票实质改版，不是仅调整共享颜色。把两图的居中主栏、浅青背景、白卡、头像／昵称头部、字号、间距、分隔和主次信息层级映射为 UP 身份、监控配置、指定目标与检查／同步状态；表单、按钮、模式切换和错误提示采用同一控件语汇。两图没有对应管理功能布局，记录这是参考视觉规则的映射，不伪称 B站管理页一比一截图，也不另做一套风格。
- 管理保留 UID 新增、逐 UP 独立草稿／保存、近期 N／指定模式、启停、目标增加／移除、删除／重新添加及状态只读重读；未检查、无变化、同步中、失败／部分完成、分项完成但整轮待确认和实际时间不能混淆。停用／删除后的保留记录仍可读，不新增自动轮询或为了填满卡片触发上游检查／同步；首期无鉴权风险改由部署文档声明，管理页不再常驻风险横幅。
- 正常生产装配与显式 mock 采用同一视觉实现；不能只把 demo 改好，而真实归档页面仍保持旧样式。

## 基准建立与公开页面取材

先建立可复核基准，再逐区域实施。这是本票首个交付步骤，不是另开无限调研票。

- 两张本地参考图为首要依据。记录各可比区域的布局标注、字体／字号／行高、颜色、边距、元素尺寸及对应页面；对当前页面明显不同的卡片头部、按钮式评论入口、图片灰底大框等逐项核对，不直接假定应该保留现状。
- 原图 712×661／763×747 是图片像素尺寸，未记录 CSS 视口、DPR 或缩放；不能直接当作来源页面视口事实。记录已知条件、推定和限制，确定可复核的缩放／区域对应方式；基准存在歧义时明示差异，不伪造来源条件或自行降低成“风格相近”。
- 首轮只以截图为基准、未授权读取真实凭据。2026-10-14用户补充当前两张图，指定`t.bilibili.com`和`bilibili.com/opus/1258559532414533635`，并授权使用本机Cookie只读查看。最新基准改为新图与该两页正常渲染后的DOM／CSS量测，详见[当前取材记录](../visual-35-live-reference.md)；Cookie仅进程内、域限定、非持久浏览器使用，不进入日志／源码／运行依赖，不采集历史／触发业务采集／绕过权限。正常网页自身渲染请求必须与另行构造采集请求区分，来源未确认项明示，不伪造条件。
- 不把 B站整站 JS/CSS、采集脚本或第三方网络逻辑当运行依赖，不执行本地 ignored 参考脚本。原参考素材保持当前文档归属，不强制加入 Git；素材缺失时申请补充并标 `needs-info`，不能仅按文字配色猜测后宣称复刻通过。

## 核验标准

- [ ] 建立列表／详情的原图对照基准和量测记录；另建立管理页按同一视觉规则映射的基准，两种证据类型明确区分。记录对照区域、渲染条件、业务内容差异和比较方法；原图与阅读实现可并排核对，管理方案可逐项追踪至参考视觉规则，不只提交“参考 B站风格”的文字说明。
- [ ] 列表的全部／单 UP 选择条、居中主栏、卡片头部、正文／展开、图片容器及评论图标／数量按列表图对齐；图标、头像尺寸、排版和间距不能被通用大按钮、任意圆角或大块占位替代。
- [ ] 详情、评论标题／数量／排序、一级评论、UP 标识、回复头像／缩进／展开按详情图对齐；正文全文和发布时间继续正确展示；按用户预览决定，归档分项状态留在接口／管理，不放阅读正文的额外信息块。
- [ ] 单图、四图、其他多图、超过九图、长图、未知尺寸及 pending/failed 图片的容器和留白合理，不用裁切、拉伸、隐藏未归档状态或请求来源图制造截图一致。
- [ ] 在确定的参考比较条件下提交受控页面截图、并排／差异图及可复测方法；遮罩只排除可变账号、正文、图片、计数等内容，不遮罩容器、图标、间距或结构偏差。基准不得由当前实现截图直接生成再自证一致；容差和未对齐项必须说明，不为通过测试随意放宽。
- [ ] 360/390/768/1280px 无整页横向溢出，只有选择条允许局部横滑；保留主要触控约 44px 与明确焦点。非参考尺寸适配保持同一结构和视觉比例，不简单缩放整张位图。
- [ ] T1 经生产 Adapter 验证 scope→卡片／气泡→详情→评论排序／回复／两类图片→返回；内部图片、选字、展开不误导航，分页、取消／迟到结果、预览历史和阅读恢复不因视觉修改倒退。
- [ ] 管理页的 UP 卡片、配置表单、模式／启停控件、目标列表、分项状态与反馈均实质采用参考视觉体系，不只换背景色；多 UP 草稿／操作独立，loading/error/重试/停用/配置删除和旧记录均可操作，四宽度及键盘验证通过。
- [ ] 经生产 ManagementApi 回归 UID／配置／目标／启停删除／重新添加／只读 checks，保留防重、取消和迟到结果隔离；正文 unknown/error/部分完成、长昵称／URL／emoji、成功空及局部失败保持可读，不能在静态假卡片上复刻或抹掉错误。
- [ ] 输出本票验收记录、实际测试命令／结果、截图及差异证据路径、未验证事项。自动化比较与正式 Linux Chrome／iPhone Safari 人工视觉签收分别记录；未对齐区域不能被功能回归通过掩盖。
