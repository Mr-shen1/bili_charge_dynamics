## 核验标准

- [x] 实际归档回复按服务端顺序展示，25 条累计 3/13/23/25；来源数为零无展开入口，未知不伪装为零，结束不再请求。
- [x] 收起恢复最多三条可见范围但保留已读数据/cursor，再展开复用已加载范围、不重复请求；切根评论排序重置回复展开，不继承另一排序状态。
- [x] 回复首次/追加失败仅影响该根评论，其他根和已有回复继续可读；同批连点不重复，失败原批重试。忽略取消时旧成功/失败/完成不改变新根、排序或详情访问。
- [x] 扁平显示可用“回复 @某人”，缺目标不拼错误文本；UP 标识按动态作者 ID，覆盖同名不同 ID。只读点赞和缺昵称/头像/时间/计数兜底正确，头像昵称不导航。
- [x] 超过六个实际渲染行才折叠，换行/emoji/长 URL 安全文本展示；空回复用“暂无评论内容”，不泄漏 undefined，不增加写回或转发。
- [x] 同动态不同历史访问分别恢复排序、多批评论、回复/文本展开、cursor、锚点/位置；数据和布局先于定位，有限后备且用户滚动优先，主动顶部/评论入口覆盖旧位置。
