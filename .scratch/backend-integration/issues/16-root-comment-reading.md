## 核验标准

- [x] 生产 Adapter 将真实评论 HTTP 映射到已有详情，初访默认最热；45 条按 20/20/5 加载并遵循 #15 的服务端完整集合排序，结束不再请求，不在页面重排当前批冒充全局排序。
- [x] 切最热/最新定位评论区，重置首批、文字/回复展开与旧请求，保留上方动态；失败留在目标排序，不显示旧排序充当新结果。受控 Reader 忽略取消时旧成功/失败/完成都不能串入。
- [x] 首次加载、成功空、有内容、未归档、失败、追加及结束区别展示；追加失败保留已有评论并原位重试同批，重复点击不重加、不漏批。
- [x] 气泡图标和来源评论数到同详情评论区，无真实评论缩略图、独立评论页或“查看详情”；主动定位优先于旧位置，历史访问保存本票排序/已加载评论/展开和位置，后续回复状态可由 #18 接续。
- [x] UP 标识按当前动态作者 ID，覆盖同名不同 ID；头像昵称仅展示、点赞只读。来源总数和本地根/回复数分别表达，未知“—”与零不同，不拿已加载数补来源数。
- [x] 白卡、粉色层级、绝对北京时间、缺头像/昵称/时间等兜底正确；评论超过六个实际渲染行才折叠，详情动态全文，换行/emoji/长 URL 和恶意文本安全显示，无转发和写回。
