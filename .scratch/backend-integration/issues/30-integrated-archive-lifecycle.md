## 核验标准

- [ ] 管理 UID/模式/目标→fixture 检查/同步→真实 SQLite→HTTP/生产 Adapter→列表/详情/评论图→返回至少形成一条穿透链路，OSS 仅模拟，浏览器使用受控图片服务。
- [ ] 停止/删除配置、删目标、模式切换、窗口移出及上游消失后，有旧归档的 UP 仍在选择条；全部/单 UP/详情、根回复及两类媒体均可读，不只靠旧详情 URL，scope/分页/访问恢复不串。
- [ ] 可信 HTML 编辑时间变化自动经公共同步更新正文与动态图来源、上传和页面；单图失败保留正文/旧成功媒体，无新信号也恢复，不用 pub_ts/内容比较触发，不回退 B站业务图。
- [ ] 来源总数变化自动更新必要根回复及一级评论图；评论文本不等全图上传，图片失败不倒退评论 checkpoint，纯图评论和不同 owner 预览正确，不扩展回复图。
- [ ] 管理 API/UI 聚合区分未检查、可信无变化、同步中、部分完成、失败及具体未完成项，最近检查/实际分项成功时间准确；一项成功、HTTP 可读或“发现成功”都不能冒充全部归档完成。
- [ ] 正文受限/编辑信号未知不挡可读评论，计数/页/图失败不归零清档；旧/新观察交错、无新信号重试和重启在组合路径有证据，保留原读取、导航、焦点和故障回归，无旧按钮/转发/独立评论页/凭据 UI。

## 测试与完成证据

T1–T3 使用真实 SQLite、公开执行/HTTP 入口、生产 Adapter 与少量浏览器穿透；模拟外部 I/O 而非全 mock 存储。每条组合给出可复现命令和证据，虚构秘密脱敏；与 #29 核对父 #11 原清单后交给部署验收，不宣称实际持续运行已通过。
