## 核验标准

- [ ] 记录代码/构建版本、部署地址的非敏感说明、测试日期、系统/浏览器版本、iPhone 型号及实际操作方法；Linux Chrome 和 iPhone Safari 分开给结论。
- [ ] 在两环境执行 scope 切换、卡片到顶部/气泡到评论区、内部操作不导航、评论排序/回复展开、多批读取与来源返回；同动态多访问和刷新无循环，位置恢复不覆盖主动滚动。
- [ ] 动态组及至少两评论图组点击打开正确序号，后退先关、前进恢复、关闭回位置/触发处；坏图仍可切换/关闭，键盘环境方向键/Esc/焦点明确。
- [ ] iPhone 真机验证横向切图、纵向长图不误切/不滚底层、完整/适宽与切图位置重置、浏览器返回不多退；触控和慢加载下仍可操作，不只看截图。
- [ ] 核对 #35 后版本的参考图保留区域一比一视觉基准、四约定宽度自动化布局证据及真机实际可见布局，逐项签收卡片/详情/评论/回复的比例、间距、字号、图标和图片容器；监控管理的 UP 卡片/配置/目标/状态按同一视觉规则映射签收并回归操作。必要业务差异明确记录。长昵称/文本/图片不造成页面横向溢出，选择条内部横滑、主要触控约 44px、详情全文/绝对时间成立。
- [ ] 每场景记录通过/失败/未验证及复现步骤和可复核截图/录屏或操作记录；失败关联修复/复测，不以桌面自动化、模拟器或移动 Chromium 标记 iPhone 通过。

## 完成与证据边界

缺设备、部署或无法执行时保持未验证并说明，不能仅写步骤就宣称正式兼容通过。将证据交给 #32 台账并供父 #12 收口；本票不授权真实上游/OSS 请求或变更生产环境。
