# 06: 动态图片 OSS 归档与预览

**What to build:** 已选动态的全部图片经服务端下载并上传公开 OSS，阅读者通过实际归档 API 在基础列表和详情查看有序图片、预览及长图；某张上传或浏览器加载失败只影响该图，关闭预览后阅读位置和焦点保持。

## 核验标准

- [ ] 扩展 02 的公开同步执行能力，从动态协议 fixture 到服务端下载、模拟 OSS 上传、实际临时 SQLite、HTTP/生产 Adapter 和页面贯通；自动化只用可控传输及模拟上传，不采购 OSS 或调用真实凭据。
- [ ] 每张图保存动态 owner、有序关联、可用尺寸、来源地址、公开 OSS 地址及上传状态/错误；全部图片都保存，九格是列表展示限制而非数据上限，重复同步不重复关联或改变顺序。
- [ ] 文本成功与图片成功独立；首次未上传明确待处理/失败，单图失败保留其他图和旧成功媒体，可独立重试且数据库重开恢复，不把正文 checkpoint 冒充所有图片完成。
- [ ] 生产浏览器直接使用 API 给出的公开 OSS URL，不拼桶地址/域名/参数、不经应用服务器代理、不回退 B站业务图；头像可沿用外链，浏览器加载失败与服务端尚未上传状态分别表达。
- [ ] 在慢下载/上传暂停期间，另一归档读取或配置写入仍能完成，以外部行为验证网络/OSS 不占 SQLite 长事务；不绑定私有锁、线程数或虚构毫秒性能阈值。
- [ ] 纯文字不留空图区，纯图动态不补空正文；单图保比例并限制列表高度，四图两列、其他多图三列，列表超过九图提示剩余数量，详情缩略及预览可访问全部且保持来源顺序。
- [ ] 点击列表/详情缩略图直接打开所属动态组及对应图片，显示当前/总数，首尾不循环、单图隐藏切换；图片操作不触发卡片导航，不需要 03 的新列表入口。
- [ ] 桌面方向键/Esc、关闭/切换控件和手机横向触控有效；长图完整/适宽模式保比例不裁切，纵向阅读不切图、不滚底层，切图重置纵向位置，不新增自由/双指缩放或下载。
- [ ] 预览焦点保持内部，关闭恢复底层位置和触发焦点或合理后备；后退优先关闭不多退，前进恢复有效预览，切图不逐张压栈，刷新遗留标记有界清理不循环。
- [ ] 坏图显示局部可理解提示并能重试、切走、关闭，不阻断其他图/正文；原读取、导航、焦点及位置测试保留，图片慢加载、缺尺寸和宽度变化不使迟到恢复覆盖用户滚动。
- [ ] 缩略懒加载、预览按需请求并预留合理尺寸；打开一图不预先请求整组原图。测试单/四/九/超过九/长图/坏图及四种约定宽度，不以 CSS 缩小或 OSS 宣称已压缩/性能达标。
- [ ] 编辑后的同一公开同步调用可重新读取整条正文及媒体来源、提交实际处理版本并保留独立媒体工作；失败不清旧成功媒体、不吞较新版本。不实现周期检测，后续 08 可调用该能力，最终自动编辑联动由 11/12 组合验证。

## 测试入口与实施边界

T3 用结构保持的虚构 HTML/JSON、延迟/失败下载和模拟 OSS 观察公开归档状态；T2 验证实际 SQLite/HTTP、关系顺序、重开和短事务行为；T1 经生产 Adapter 与可控图片服务验证网格、组、资源请求及浏览器历史/焦点/手势。模拟触控不冒充 iPhone 真机。

不依赖 03、04 或 08，不在本票加入评论图片、回复图片或周期调度。编辑触发依据始终为 HTML 作者模块可信“编辑于”时间，不改成 pubts、正文或图片差异比对。图片尺寸变体、处理/CDN/费用尚未批准，不擅选、不加签名续期；凭据只在服务端仓库外，测试全部虚构/脱敏。
