## 核验标准

- [x] 对停用 UP、删除配置、删除指定目标、切近期/指定模式、窗口移出逐项验证：后续不发起新检查或领取新工作，指定/近期互斥，重新纳入后能恢复应有工作。
- [x] 分别在检查中、同步待领取、正文/根回复/图同步中以及提交前后改变配置；旧工作不挂到新配置/错误 UP、不吞新工作、不把已停目标重新激活。允许正确保存已取得结果，但停止期间不继续开启新监控。
- [x] 保存身份、正文、根评论、回复、动态/评论媒体全部 owner/顺序/URL/状态及未完成信息；上游消失、拒绝、失败和配置删除都不清旧成功归档。
- [x] 在上述边界关闭重开真实 SQLite/重启采集，启用目标恢复固定检查，停止/移除不复活；observed、分项 checkpoint 和待处理保留，旧完成不清较新观察，重复提交幂等。
- [x] 慢检查/同步/上传时归档 HTTP 和配置写入仍能完成，网络不占长事务；固定 15 秒忙检查跳过无积压、慢同步不禁止新检查，未知/失败不变成成功零。
- [x] 用公开状态、实际归档和外部请求记录证明“已停止且旧内容可读”“重新纳入后继续待处理”，不是只断言内部取消标志；错误脱敏，虚构秘密不出现在 API/日志。
