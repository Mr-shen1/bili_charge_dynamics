# 03: 全部／单 UP 列表与卡片改版

**What to build:** 阅读者默认在 `/` 浏览所有 UP 的保留归档，通过横向头像昵称选择条进入 `/ups/:upId`；列表先全局排序再分页，卡片以 B站裁剪样式展示实际作者，点击或键盘进入详情顶部，跨范围返回恢复各自阅读进度。

**Blocked by:** [02: 指定动态首次归档与阅读](02-target-initial-archive.md)

**Status:** ready-for-agent

## 依据

- [父规格](../spec.md)：故事 1–17、28–35、45、46、60–63；I3、I8–I11；T1、T2。
- [SRS](../../../docs/SRS.md)：FR-01–FR-05、FR-10–FR-13、FR-19、DR-01、DR-02、NFR-01–NFR-04；AC-01–AC-05、AC-12–AC-18、AC-21、AC-29、AC-31（本票范围）。
- [HLD](../../../docs/HLD.md)：第 3–6、8、9 节；[UI 文字规范](../../../docs/ui-reference.md)。

## 核验标准

- [ ] `/` 默认读取全部已归档动态，`/ups/:upId` 读取该 UP 完整归档；顶部“全部 + UP 头像昵称”选择条横向可滑，停止/删除配置后有归档的身份仍有入口，不只读取启用名单，范围切换不触发采集。
- [ ] 至少两 UP 的交错及并列时间共 25 条归档，经实际临时 SQLite/HTTP 与 Adapter 验证全部先全局排序再按 10/10/5 追加，不按 UP 分页后拼接；单 UP 独立排序，发布时间降序、ID 字符串非语言环境升序，逐字段缺失排有效值后，不把 ID 转数字。
- [ ] 在实现前明确动态读取期间插入/更新的分页一致性契约并测试其声明范围不重不漏；失败不推进 cursor、重试同批，连点不重复追加，结束不再请求，不能靠去重掩盖漏批。
- [ ] cursor、缓存、请求身份、访问快照均绑定 scope 和读取上下文，跨范围 cursor 不静默复用；受控 reader 即使忽略取消，旧成功、旧失败、旧完成均不能污染新 scope 或清除其加载状态。
- [ ] 每条卡片及详情以实际 `dynamic.author` 显示作者，不用旧全局 creator；保留同名不同 ID 身份测试，评论/回复已有 UP 标识按当前动态作者 ID 判断，不虚构真实评论采集。
- [ ] 卡片整体点击/键盘激活进入详情顶部，完全移除“查看详情”；气泡图标与来源评论数量可保留为同一详情评论区定位入口，不用真实评论缩略图、不新增独立评论页。
- [ ] 图片预览、文字选择、展开/收起及内嵌操作不误触卡片；内容头像昵称仅展示且不冒泡导航，点赞只读，入口具有合法交互语义、清晰焦点及约 44px 触控区域。
- [ ] 浅青背景、白卡、青蓝选中、粉色作者及内容层级符合 UI 文字规范，手机单列、桌面不加复杂侧栏；无任何转发图标/数量/操作或空占位，无简介、推荐、购买解锁等未定功能。
- [ ] 列表超过六个实际渲染行才折叠，宽度变化重判，详情动态始终全文；换行、emoji、长词/URL 正常、安全文本无富文本跳转，保留独立发布时间/编辑精度、来源计数与零/未知兜底。
- [ ] 从详情返回有效站内来源 scope 的多批数据、cursor、展开和阅读锚点/位置；无有效来源返回 `/`。同动态多次访问互不覆盖，主动卡片/气泡定位优先于旧位置，用户滚动优先于迟到恢复。
- [ ] 直接访问或刷新两种列表及详情能读取；未知 UP、已知 UP 空归档、未知页面、本地动态不存在、网络失败分别显示并可合理返回/重试，上游消失不删除旧归档。
- [ ] 在 360、390、768、1280px 检查正文/长昵称/选择条不使页面横向溢出，仅选择条内部可横滑；保留原读取、导航、焦点、布局恢复及独立 mock 回归，图片能力当前只验证已有边界而不冒充 OSS 完成。

## 测试入口与实施边界

T2 在真实临时 SQLite 验证跨 UP 排序、cursor 和更新期间一致性；T1 经生产 API Adapter 的传输替身与少量实际 API 场景验证 UI，RTL 控制乱序，Playwright 验证布局、键盘、历史及位置。自动化移动视口不等于 iPhone Safari 真机证据。

本票不依赖 [04](04-root-comments.md)：已有气泡入口与同详情评论定位保留，真实根评论由 04 接入；若尚未归档评论，明确表达未同步状态，不展示虚构来源评论作生产内容。04 不等待本票的新列表；组合回归在后续整合/交付执行。OSS、评论图片和监控调度不在本票。URI scope 仅表达归档阅读范围，不增加仅评论采集模式。
