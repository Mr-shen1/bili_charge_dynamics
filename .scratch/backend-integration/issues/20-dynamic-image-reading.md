**What to build:** 生产 Adapter 接入 #19 的公开图片与状态，在已有列表/详情显示网格并复用预览；图片局部故障不影响正文或阅读位置。

- [SRS](../../../docs/product/SRS.md)：FR-02、FR-08–FR-12、DR-03、NFR-02、NFR-03；AC-09–AC-12、AC-14–AC-17、AC-30 的动态图展示部分。
- 遵守[共同交付要求](../implementation-plan.md#所有执行子票的共同交付要求)。复用现有图片/导航能力，预览身份明确 owner 类型、owner ID、组内图片和触发处，供 #22 接入评论 owner。
- 不等待 #14 新列表，不增加评论/回复图、自由缩放、下载或生产来源图回退；不以 CSS 缩小或 OSS 宣称压缩/性能已达标。

## 核验标准

- [ ] 生产 Adapter 保留全部图片及状态，浏览器直接请求 API 给出的公开 OSS URL，不拼接、不经应用代理、不回退来源业务图；头像外链不受此规则误伤。
- [ ] 纯文字无空图区，纯图无空正文提示；单图保比例并限制列表高度，四图两列、其他多图三列，列表最多九格且提示剩余数，详情缩略与预览可访问全部。
- [ ] 点击所点图片打开正确动态图组和序号，显示当前/总数；首尾不循环、单图无切换，图片操作不触发卡片导航。
- [ ] 方向键、Esc、按钮及手机横滑有效；长图完整/适宽不裁切，纵向阅读不误切/不滚底层，切图重置纵向位置。焦点留在预览内，关闭恢复触发处或合理后备。
- [ ] 后退优先关闭、前进可恢复有效预览，切图不逐张压栈；关闭恢复底层访问与位置，刷新失效标记有界清理，慢图片/缺尺寸/宽度变化不让迟到恢复压过用户滚动。
- [ ] 归档未上传与浏览器坏图分开提示；坏图能局部重试、切走和关闭。缩略懒加载、预览按需，不为打开一张预先请求整组原图；四宽度、触控与焦点合格。
