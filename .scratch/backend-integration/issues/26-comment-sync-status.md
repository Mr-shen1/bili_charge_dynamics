## 核验标准

- [ ] API/生产 Adapter/卡片或详情评论区明确区分来源总数、本地根数、本地回复数与当前已加载数，不相互代填；未知显示“—”、零显示 `0`、已知计数完整非负整数，不用缩写隐藏差异。
- [ ] 经 fixture 同步产生来源数大于本地数、页失败、成功空等真实状态，UI 如实展示；归档 HTTP 成功不意味着采集完整成功，评论文本完成不意味着图片完成。
- [ ] 管理页可读评论未检查/待处理、同步中、部分完成或失败，以及最近检查、对应分项成功时间和脱敏错误；检查无变化不更新同步成功时间，不展示伪造时间。
- [ ] 计数缺失、正文受限/网页无权但评论可读、根/回复页失败时保留旧内容和可信数；后台无新信号重试成功后公开状态更新，不要求用户重新建目标或清空归档。
- [ ] 阅读排序、分页、追加失败原位重试及访问隔离继续有效；状态刷新不清已加载评论/位置、不触发上游采集，迟到响应不覆盖新访问或目标状态。
- [ ] 以可理解说明记录总数抵消/纯评论编辑且总数不变可能漏检，不宣称完整来源评论、实时性或所有受限评论可读；错误和来源文字安全显示，无虚构秘密泄漏。
