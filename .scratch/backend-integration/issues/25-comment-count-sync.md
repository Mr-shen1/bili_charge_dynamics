## 核验标准

- [ ] 原始 JSON 经公开检查入口取得来源总数（根+回复）并保存可信 observed；除初始化/失败重试外，仅总数变化触发根回复同步，仅正文编辑或总数不变不默认重扫。
- [ ] 用结构真实 fixtures 核验映射，不能从首屏、本地已加载数或历史样本恒等推导总数，也不擅自省略未证实冗余的计数读取。缺失/无效/拒绝/业务或网络失败不是零，不覆盖旧可信值。
- [ ] 同步处理该轮必要根评论和回复的完整分页，包含已有可读内容；不加“遇到旧 ID 就截断”、每日校准、内容比对或全历史动态回填。真实零、增加、减少、不变、增删抵消和纯编辑分别测试并记录漏检边界。
- [ ] 首次计数未知、无编辑标记、正文受限或网页无权仍允许实际可读评论初始化；实际接口拒绝如实失败，不归零、不清旧归档。
- [ ] 任一必要页失败不推进整轮评论 checkpoint，成功部分保留，无新信号也重试。旧同步中观察新计数，旧完成不冒领新版本/清新工作；重开、重复提交幂等。
- [ ] 评论文本、正文与媒体独立推进；慢评论分页不阻断新检查/其他目标，网络不占长事务，旧归档 HTTP 仍可读。公开状态区分 observed、评论成功版本、本地数量、待处理及脱敏错误。
