# 03: 楼中楼回复精确链接

**What to build:** 从本站链接直接看到某条具体楼中楼回复，包括后续页回复，自动加载、展开、定位并高亮，适配宽屏和手机独立楼中楼阅读。

**Blocked by:** 02 一级评论精确链接。

**Status:** ready-for-agent

## 上下文与范围

依据：[实施规格](../spec.md)、[正式需求与设计](../../../docs/design/feishu-notifications.md)、[领域词汇](../../../GLOSSARY.md)。对应用户故事 46–50、57；验收关联 FS-AC-11。

依赖 02 的身份定位读取与主动入口语义，将契约扩展为动态、所属根评论及目标回复。复用原宽屏回复页码和窄屏楼中楼页，不能把“到某个根评论”当成“到某条回复”。本票不依赖通知进程。

## 验收条件

- [ ] 明确并实现稳定回复链接及只读定位响应，返回足以显示目标及所属根上下文的数据；校验动态、根和回复归属，不串楼。
- [ ] 一根超过 10 条回复、目标不在首屏或首个预览的情况下，宽屏自动展开并显示目标所在页，定位高亮准确。
- [ ] 窄屏独立楼中楼入口直接显示指定回复所在页并高亮，不强制把所有精确入口重置为第一页。
- [ ] 首次打开、直开、刷新均不依赖旧内存或用户先读过根评论；回复正文在定位时可阅读，不被折叠隐藏。
- [ ] 定位不一次渲染全部回复，原页内替换、后续翻页、收起及普通无精确目标的首屏行为保持。
- [ ] 正常返回与历史恢复符合原有访问规则；主动定位完成后不持续拉回目标，迟到响应不污染新的动态或楼层。
- [ ] 目标删除/缺失、归属错误与暂时读取失败有区分；明确提示并提供返回对应动态入口或局部重试，不静默显示楼层顶部冒充成功。
- [ ] 归档定位不请求 B 站；链接不包含凭据，保持代理保护，不增加回复图片采集或额外上游查询。
- [ ] 生产前端＋HTTP 替身覆盖宽窄屏及后续页，真实 API＋隔离数据库证明任意归档回复可定位；回归 02 的一级评论入口。
- [ ] 记录供 05 使用的回复定位契约及结果，真实客户端未验证项单列。

## 验证方式

沿用现有回复 10/10/5 页内替换、窄屏楼中楼与历史恢复的生产装配场景，补目标处于后续页、实时数量变化、快速跨楼切换等受控测试。测试外部传输而不模拟浏览器定位函数；真实 API 测试只使用隔离数据库。

## 完成与后续

交付回复精确链接的完整读取到浏览器行为。05 将该链接接入消息，11 独立验证飞书客户端和手机实机；本票不发送真实飞书消息。
