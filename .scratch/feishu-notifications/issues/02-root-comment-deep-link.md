# 02: 一级评论精确链接

**What to build:** 打开本站链接即可看到指定一级评论，即使它在后续批次，也会自动加载、展开、定位并高亮；直接访问、刷新和返回均可用。

**Blocked by:** 无（可立即开始）。

**Status:** ready-for-agent

## 上下文与范围

依据：[实施规格](../spec.md)、[正式需求与设计](../../../docs/design/feishu-notifications.md)、[领域词汇](../../../GLOSSARY.md)。对应用户故事 45、47–50、57；验收关联 FS-AC-11。

本票贯通归档读取契约、生产前端 Adapter 与阅读入口，不依赖飞书投递设施。复用现有详情和一级评论阅读，不另建独立完整评论阅读器；后续 03 扩展到回复，04 在消息中使用本票的稳定链接契约。

## 验收条件

- [ ] 明确并实现以动态和目标评论身份定位的稳定链接与只读归档契约，必要的上下文可可靠取得；ID 保持字符串，不依赖旧会话或已加载 DOM。
- [ ] 超过 20 条一级评论的样本中，可直达非首批目标；自动取得所需数据、展开被折叠的目标正文、定位并高亮。
- [ ] 读取与定位不要求一次渲染全部评论，不破坏既有排序、分页及后续正常阅读；不把页首当作精确定位结果。
- [ ] 首次打开、直接访问、刷新、宽屏与窄屏均正确；明确的主动入口定位完成后不持续抢占用户滚动。
- [ ] 普通详情入口、评论区入口和历史返回继续遵循原有恢复规则；定位后的返回不会无故清空来源列表或跨访问污染。
- [ ] 动态与评论身份不匹配或目标不存在时给出明确提示与返回对应动态入口；临时加载失败与不存在分开，可重试。
- [ ] 快速切换链接或迟到响应不会定位、覆盖或高亮另一条访问中的评论。
- [ ] 只读定位仅访问本地归档，上游请求计数为零；凭据不进入 URL，保留代理访问保护，不新增应用账号体系。
- [ ] 生产装配＋归档 HTTP 替身覆盖主要浏览器场景，补真实 API＋隔离 SQLite 场景证明目标可读取和无采集副作用；各类证据分别记录。
- [ ] 记录链接和读取契约供 03、04 复用，并按项目约定声明新增浏览器测试所属项目；不增加真实飞书验证前置条件。

## 验证方式

复用已有评论 20/20/5 批次、生产 Adapter、窄屏和历史恢复测试模式。使用实际前端路由与阅读逻辑；HTTP 替身只负责归档响应，不替代定位行为。真实 API 场景使用独占临时数据库，禁止对现有运行实例注入样本。

## 完成与后续

交付可通过浏览器直开演示的一级评论链接及契约证据。楼中楼具体回复由 03 完成，真实飞书内置浏览器及手机实机由 11 验证；本票自动化不冒充真实客户端通过。
