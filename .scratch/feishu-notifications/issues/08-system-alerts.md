# 08: 系统告警闭环

**What to build:** 真实可判定的运行故障向独立系统群发送脱敏告警；同对象同类故障首次提醒，此后每 30 分钟最多一次，重启也不刷屏，系统群自身失败不递归告警。

**Blocked by:** 06 双群独立投递与故障恢复。

**Status:** resolved

## 上下文与范围

依据：[实施规格](../spec.md)、[正式需求与设计](../../../docs/design/feishu-notifications.md)、[领域词汇](../../../GLOSSARY.md)。对应用户故事 15、51–53、58；验收关联 FS-AC-10、12。

接入真实来源/采集失败以及 06 的路由、投递失败事实，复用持久队列与独立通知进程，不用扫描或解析任意日志文本伪造业务失败。系统群与 UP 群/全员群的业务用途分开。

## 验收条件

- [x] 五类告警都有可验证触发链：可信凭据失效、采集异常、主循环异常、飞书持续投递失败、路由缺失或错误。
- [x] 普通超时或网络故障不冒充登录失效；无可信凭据失效信号时保持实际错误类型。正常计数增长或采集期间新增评论不生成故障告警。
- [x] 告警只发系统群，业务评论不混入系统群；消息采用类别、对象、发生时间及固定脱敏原因，不包含凭据、响应正文或异常原文。
- [x] 同对象同类故障首次提醒，此后每 30 分钟最多提醒一次，跨重启保留节流状态；不同对象和不同类型分别判断。
- [x] 未投递的同类提醒不会每次重试或每轮采集无限生成；明确定义并验证持续投递失败的判定和提醒合并策略，保持已确认节流上限。
- [x] 采集或主循环发生可捕获异常时可靠登记告警；不把进程被强杀、整机离线或数据库完全不可写时的即时告警能力写成保证。
- [x] 缺失或错误业务路由保留原业务消息并产生系统提醒；修复后业务补发不重置历史基线、不重发已成功目标。
- [x] 系统群未配置或发送失败时留本地脱敏诊断并按原任务等待/重试，不递归产生系统群投递失败告警，不转发到业务群。
- [x] 不增加故障恢复消息、飞书图片上传降级消息、免打扰或日上限；告警退避与采集固定节拍独立。
- [x] 对五类触发、首次/边界时间、重启、重复故障和系统群失败取得受控主链证据，不仅测试一个消息格式函数。

## 验证方式

使用真实错误登记与通知模块、临时数据库、受控飞书接收端及时间。故障从实际来源/采集/投递入口注入，不借真实凭据失效或真实群失败制造测试。检查输出脱敏；与心跳的组合隔离由 10 收口，不将 09 作为本票前置依赖。

## 完成与后续

交付五类告警到受控系统群的闭环、节流/递归防护证据及真实能力限制说明。真实系统群行为在 11 经授权后验证。

## Answer

**已完成并取得自动化主链与迁移证据；真实凭据失效与真实系统群未验证。** 实施与逐条验收证据见 [evidence/08-system-alerts.md](../evidence/08-system-alerts.md)。

- 五类触发：可信凭据失效（只认上游业务码 `-101` 且本次启动确实读到来源凭据，匿名 `-101` 归 `login_required`）、采集异常（检查/同步/发现的显式失败）、主循环捕获异常、飞书持续投递失败（`failures >= 3` 且 `state=pending`，排除心跳与告警自身）、业务路由缺失/错误（`route_missing`/`route_invalid`）。全部来自真实代码路径，不解析日志文本、不新增上游探针。
- 不冒充：`-111/-352/-401/-403/-412/-799` 等业务码、HTTP 401/403、超时与网络异常一律保持原分类；正常计数增长、采集期间新增评论与普通“待同步/媒体待完成”都不告警。
- 节流与合并：同一 `(category, object)` 首次立即提醒，此后每 30 分钟最多一次；节流状态持久在 `notification_alerts`（v21），跨重启保留；上一条同类提醒未投递完成时新的同类故障合并到它，因此系统群长期失败也不会堆积。
- 脱敏：消息只有类别、对象、北京时间发生时间与固定原因短语（白名单 + 受控对象字符集），不含凭据、响应正文、异常原文或业务评论正文；无恢复消息与图片降级消息。
- 不递归：系统角色自身的缺配置、投递失败、心跳失败与告警失败只留本地脱敏诊断与 `failures` 事实，不再生成新告警，也不转投业务群。
- 可靠性边界：采集/投递侧告警与失败事实同事务登记，单条告警用 `SAVEPOINT` 隔离（写不进只留 `alert_registration_failed`，不让主链回滚）；主循环异常在退出前用独立短事务登记；整库不可写、强杀与整机离线只承诺脱敏日志。
- 迁移与集成：05 已占 v20，本票顺延为 v21（只新增 `notification_alerts`）；完成前已 `merge --no-ff cef38ff` 并入 05 并重跑全量。
