# 01：统一 B 站请求发送入口

Status: ready-for-agent

**What to build:** API 与采集进程的所有 B 站源请求经过统一的发送许可／结果报告 Interface，使后续风控和等待规则能覆盖全部真实发送；本票是保行为预重构，不提前改变正常采集策略。

**Blocked by:** 无（可立即开始）。

## 验收标准

- [ ] 通过真实应用和 collector 装配、临时 SQLite 与外部传输替身，验证计数、根评论、楼中楼、feed、detail、动态网页、UP 资料、首页／空间预热和图片下载均经过统一入口。
- [ ] HTTPX、Requests、媒体下载各 Adapter 均能在发送前取得许可、返回后报告状态；受信域内重定向的后续发送也有明确接入位置，不能只观察最外层调用。
- [ ] API 的资料查询、作者校验、手动初始化和媒体重试复用同一 Interface，不另造只供 collector 使用的入口；跨进程持久策略由 03／08 接入，不以进程内共享对象冒充全局保护。
- [ ] Cookie、主机白名单、重定向、代理、超时、解析、会话缓存及原有有效等待保持现状，成功结果与其他错误处理不因预重构改变。
- [ ] OSS 上传、飞书投递和本地归档读取明确不受 B 站来源许可控制；阅读 GET 不产生上游请求。
- [ ] 提供可注入的时间／传输 seam，沿用实际应用和 collector 的测试入口，不复制业务解析、不另造假数据库。
- [ ] 以请求账本证明原有调用覆盖无遗漏、无额外请求及重复等待；既有正常／失败回归通过。
- [ ] 本票范围内的运行说明和装配测试同步更新；未新增风控开关、自动恢复、分页持久断点或全局串行策略。

## 验证范围

为 RC-02、RC-05、RC-09 建立发送入口覆盖先例，不单凭本票宣称这些验收项全部完成。只使用隔离替身；不访问真实 B 站或修改生产环境。
