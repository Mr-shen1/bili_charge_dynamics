# 10：多进程组合与性能验收

Status: ready-for-agent

**What to build:** 用隔离、可重复的实际运行组合证明全量归档、风控暂停／恢复、分页续采、日志和告警能够一起工作，并给出与等价全量参考策略相比的速度证据及完整交付台账。

**Blocked by:** 08 — 单路重型归档与分页公平轮转；09 — 风控生命周期系统告警。

## 验收标准

- [ ] RC-01—RC-12 均有对应命令或可重复场景、结果、样本范围和未验证项；逐票证据不足之处在本票补齐，不以单元测试数量替代运行行为。
- [ ] 使用真实 API、collector、共享临时 SQLite、实际通知进程及外部传输替身，覆盖至少 8 目标、其中含万条楼中楼回复的固定全量样本；最终归档全部可获取内容，轻量检查与所有可运行分页均有进展。
- [ ] 一进程在任一 B 站入口触发 412／429，其他进程的业务、预热和图片请求都停止；本地 GET、管理停止／删除、已取得内容提交和 OSS 上传仍可用，相关联网操作明确暂不可用且不产生半成品。
- [ ] 完整验证每档 1、2、4、8、15、30 分钟等待后都探测，各必需类型全部通过才恢复；失败短路、最后转人工、10 分钟观察再清零、观察期再触发沿用下一档均正确。
- [ ] 在请求中、冷却中、探测中和观察期分别终止／重开进程，验证唯一 owner 接管、状态与剩余期限持久、已确认页复用、新计数不吞旧进度、旧结果不能覆盖新代次；不以 FakeProcess 充当跨进程验证。
- [ ] 分页插入／删除／移动及 locator 改变时，断点验证和必要重叠读取不漏内容、不盲跳、不无条件全目标重扫；原有来源／本地计数口径、受限内容、停止／重纳入、媒体交错及冻结阅读分页回归通过。
- [ ] 全路径真实楼中楼请求后至少等待 100ms，包含增量、失败重试、空尾与探测；任务间不能绕过，跳过无网络工作的楼不付额外楼级等待。
- [ ] INFO／WARNING 足以跨进程／重启关联动态、根、每页完整评论／回复 ID、等待、断点及恢复流程；秘密、正文、完整 URL 与内部令牌负向泄漏断言通过，未新增独立日志文件或保留期配置。
- [ ] 告警遵守系统群、现有开关、去重／节流；探测不生成业务通知，真实归档提交沿用既有通知基线与资格，无新增风控页面。
- [ ] 构造工作量等价的隔离参考 Adapter，记录静态参考来源摘要与适配项；不执行、导入或提交原始参考脚本，不使用通知基线完成时间冒充全量归档时间。
- [ ] 固定目标集合、完整数据、分页大小、来源变化、网络延迟、随机种子与环境；报告总耗时、逐类请求数、显式等待、重复读及最终归档量。T_new 不超过 1.2 倍 T_reference 加每次必需楼中楼请求 0.1 秒改为非硬性参考目标，不为达标反复调优或阻塞本票及交付。
- [ ] 楼中楼页次数包含协议必需确认页，但不能靠重复请求扩大性能预算；项目独有工作等量计入两侧，无法等价时只能披露可比链路和额外成本并标注整体性能未验收，不因此阻止本票完成；未达参考目标时如实报告一次有界对照的结果，其他正确性和安全要求仍须满足。
- [ ] 后端完整回归及必要的既有前端固定错误映射回归通过；若有前端改动，遵守项目现有统一验收门槛。不修改其他错误分类、正常检测信号、校准策略或权限模型。
- [ ] 验证原子迁移与旧数据保留，同步已实施的采集／管理／归档／通知契约及运行说明，台账区分已实现、隔离已验收、真实来源未验证；不将上线、真实 B 站／OSS／飞书验证或生产日志策略调整算作已完成。

## 验证范围

本票收口全部 RC 验收项，仅使用隔离传输和受控时间。生产访问、真实限流复现、外部投递、部署、重启或回滚仍需另行授权，不能因票据全部完成而自动执行。
