### 规范轴（Standards）

初审无硬违规，提出6项启发式判断：应用层反向依赖动态模块快照类型、渲染期写 ref、折叠阈值分散、锚点查询重复、首次/追加协调器骨架重复、limit 兜底与 cursor 错误处理形式不同。

修订：快照与读取状态契约移到 `src/app/ListSnapshot.ts`，不再依赖动态 Hook；ref 改为在布局 effect 中同步已提交状态；六行阈值由 CSS 变量单处定义，CSS 用 `lh` 限高、测量读取同一变量，像素取整容差具名；锚点查询合为一个内部操作。保留两种职责不同的读取协调器，不为了骨架复用建设通用状态框架；limit 是有上限的大小输入，非法 cursor 是错误资源/批次身份，两者语义不同，保留现状。本票仍只有列表快照，不预建评论快照。

### 规格轴（Spec）

初审无阻断缺陷或范围越界。提出加载提示与禁用按钮的低优先判断、长 URL 样例证据可加强，并确认详情历史位置属于07、后备和真机限制已如实记录。保留追加加载提示与禁用按钮：一个说明局部状态，一个明确不可重复操作，符合 FR-11。正常两批长正文增加约200字符的长 URL；详情历史快照仍不实现。
