# 05：在动态中查看多图并打开图片预览

Status: ready-for-agent
Implementation: completed（仅 05 图片网格与基础预览，验收环境及未验证项见 [验收记录](../acceptance-05.md)）
Blocked by: [02：连续阅读动态并从详情回到原位置](02-continue-reading-dynamics.md)

**交付行为：** 用户在列表或详情查看单图和多图，点击缩略图直接预览、前后切换并关闭，回到原先的页面位置；图片按需加载，坏图不阻断浏览。

## 依据与范围

- [实施规格](../spec.md)：用户故事 25–28、30、33、36、47、48、50–52、55 的基础图文与桌面预览部分。
- [SRS](../../../docs/product/SRS.md)：FR-02、FR-08、FR-09、FR-10、FR-11、FR-12、DR-03、NFR-01、NFR-02、NFR-03、NFR-04。
- [HLD](../../../docs/design/HLD.md)：第 5–10 节。重点是复用页面快照、分离页面与预览标识、尺寸占位、焦点和图片 URL 边界。
- 验收关联：AC-09、AC-17 的图片部分；AC-02、AC-10、AC-11、AC-14、AC-15、AC-16 的基础预览子场景。

## 实施约束

- 依赖 02 已验证的页面访问与位置恢复机制，不建立另一套图片专用页面返回栈。
- 从读取结果接收缩略图 URL、预览图 URL、顺序及可用尺寸；准备合法的实际缩略素材，不通过 CSS 缩小原图假装减少流量。
- 预览模块发出打开/关闭意图，导航模块统一操作历史；预览 ID 与底层页面访问 ID 独立，不按路由 key 变化重置页面。

## 验收条件

- [x] 单图按比例显示且列表内限制高度；多图 4 张用两列，其他多图用三列，图片不会撑宽页面。
- [x] 列表最多 9 个缩略图位置，超过时最后一格显示未展示数量；详情显示全部缩略图，预览可访问完整图片集合。
- [x] 无正文有图正常展示，无图有正文不留空图片区，两者均为空时使用 SRS 兜底。
- [x] 从列表或详情点击缩略图直接打开对应图片，无需先跳转其他页面；预览默认完整、等比、不裁切，并显示当前序号和总数。
- [x] 按钮及左右方向键可以前后切图；首尾不循环，单张图片隐藏切换按钮；关闭按钮和 Esc 可用。
- [x] 打开只新增一条同 URL 预览历史记录，切图不新增记录；基础关闭只撤销有效的预览记录，不意外离开底层页面或二次后退。
- [x] 关闭恢复触发页面的阅读位置与焦点；底层滚动锁定在关闭后解除。Provider 与底层页面快照不因预览打开而重建。
- [x] 预览内焦点受约束，关闭后回到触发元素或合理后备位置，聚焦不能无意覆盖已恢复的滚动位置。
- [x] 列表缩略图懒加载，预览图按需请求；打开一张不要求下载全部预览图。用请求观察验证，不只检查缩略图显示尺寸。
- [x] 有尺寸时预留图片空间，缺失时先合理占位并在加载后处理实际尺寸；新增图片不破坏 02 的基本返回恢复。
- [x] 内容图片失败显示占位及重试；仍能切换其他图或关闭。头像失败继续使用默认头像，不占用内容图片错误流程。
- [x] 前端使用读取层给定 URL，不自行追加 OSS 参数或缓存破坏参数；带签名形式的样例地址保持完整，不增加代理、画布处理或下载。
- [x] 页面和浏览器测试覆盖单图、4 图、9 图、超过 9 图、坏图、列表/详情入口、键盘、基础历史关闭与焦点恢复。
- [x] 图片网格及基本预览在约定视口可用，触控目标及键盘操作符合 SRS；相关测试、类型检查、构建及既有测试通过。（Chromium 桌面/Pixel 7 模拟，非真机与跨浏览器完整验收。）
