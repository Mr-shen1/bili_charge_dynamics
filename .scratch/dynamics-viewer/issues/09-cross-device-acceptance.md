# 09：完成跨设备核心流程与交付验收

Status: ready-for-agent
Blocked by: [07：在历史访问中继续阅读评论与回复](07-restore-discussion-history.md)、[08：用静态产物直接访问页面并正确加载资源](08-static-delivery.md)

**交付行为：** 验收者可以在桌面和手机目标范围内验证完整只读浏览流程，取得可复核的测试、兼容与静态交付结果，并清楚知道哪些场景通过、失败或尚未验证。

## 依据与范围

- [实施规格](../spec.md)：全部用户故事的集成验收，重点用户故事 50、51、53、56–58；完成判定以实施规格和 SRS 为准。
- [SRS](../../../docs/SRS.md)：FR-01、FR-02、FR-03、FR-04、FR-05、FR-06、FR-07、FR-08、FR-09、FR-10、FR-11、FR-12、FR-13、DR-01、DR-02、DR-03、NFR-01、NFR-02、NFR-03、NFR-04、NFR-05；验收 AC-01 至 AC-20。
- [HLD](../../../docs/HLD.md)：第 10–13 节，结合第 4–8 节的异步、历史和恢复风险。
- 前置任务通过传递依赖包含全部功能。各票已应具备本身测试、异常处理和基本响应式，本票不承担从零补齐所有测试。

## 验收条件

- [ ] 用最终集成版本打通“列表 → 详情 → 看图 → 评论排序 → 展开回复 → 返回恢复”自动化流程，对应 AC-20，并将失败定位到相关公开行为而非通过削弱断言绕过。
- [ ] 建立可复核的 AC-01 至 AC-20 验收结果，覆盖各项子场景及全部 SRS 需求；仅引用编号或链接不算验证证据。
- [ ] 复核正常数据集至少含 25 条动态、某动态下 45 条一级评论、某评论下 25 条回复，配套时间/点赞并列、图片数量边界、长内容、空态、字段缺失和确定性故障样例。
- [ ] 复跑 HLD 第 10.2 节组合风险：访问快照隔离、预览前进后退与刷新、元数据替换、取消无效时的过期回调、加载中离开、慢图及锚点回退。
- [ ] 在 360px、390px、768px、1280px 宽度检查完整页面，长昵称、正文、评论与图片不横向溢出；不能只检查首页首屏。
- [ ] 主要触控区域约 44px，键盘可完成主要操作、焦点可见，预览焦点约束和关闭恢复正常；手机切图与长图滚动不干扰底层页面。
- [ ] 对现代 Chrome、Edge、Safari 及手机重点目标记录实际版本、设备或模拟方式，自动化 WebKit 或桌面模拟不冒充真实 iOS Safari；未验证范围明确列出。
- [ ] 复核所有兜底与错误状态：局部失败保留已成功内容，重试无重漏，不存在/未知路由/网络失败不混同，坏图不阻断切图与关闭。
- [ ] 正常产物无简介、充电业务、真实写操作、故障面板、真实 B站请求或凭据；正文脚本样例作为文本显示，URL 与计数语义符合规格。
- [ ] 以最终构建复跑 08 的正常静态产物、深链接、缺失资源及缓存验证，不能沿用较早版本结果而不核对变更；验证限制仍须如实保留。
- [ ] 全量已有测试、关键浏览器流程、类型检查和静态构建通过；结果可复现，存在环境限制时说明命令、受影响项与原因，不虚构通过。
- [ ] 源码、合法模拟数据与素材、测试、可复现构建方式与产物、Nginx 示例及验证说明齐全，交付不要求真实云资源或后端上线。
- [ ] 修复本期范围内的集成缺陷并增加相应回归验证；涉及需求或架构改变时先确认，不静默扩大功能或改写上游约定。
- [ ] 每个验收项记录通过、失败或未验证及原因；只有全部必需项满足时才宣称本期完整验收。环境受限的未验证项不能通过记录一份说明就自动算作通过。

## 验证方式与边界

沿用 Vitest、React Testing Library、Playwright 和必要的实际浏览器检查，以用户可观察结果为准。不默认引入全页面像素截图基线，不用覆盖率代替行为，不新增测试专用内部接口。验证结果与环境记录在实施交付中提供，本任务文件本身不是已完成的测试报告。

本票是集成、兼容和交付收口，不新增需求、不开展大型压测、不配置真实云服务，也不承诺无限历史容量或后续全链路性能。父规格与上游文档不因本票存在而被标记为已完成。
