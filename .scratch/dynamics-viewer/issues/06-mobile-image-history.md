# 06：在手机上阅读长图并安全使用返回操作

Status: ready-for-agent
Blocked by: [05：在动态中查看多图并打开图片预览](05-preview-dynamic-images.md)

**交付行为：** 用户在手机上滑动切图和阅读长图，使用返回、前进或刷新时不会意外离开底层页面，也不会陷入空弹层或导航循环。

## 依据与范围

- [实施规格](../spec.md)：用户故事 29、31–35、42、47、50、51 的长图、触控与预览历史部分。
- [SRS](../../../docs/SRS.md)：FR-09、FR-10、FR-11、NFR-01、NFR-02。
- [HLD](../../../docs/HLD.md)：第 6–10 节，特别是第 7 节预览历史与失效标记、第 8 节恢复责任方。
- 验收关联：AC-10、AC-11 的完整预览场景，以及 AC-14、AC-16 的相关子项；同时验证 HLD 的预览前进恢复与刷新降级。

## 实施约束

- 延续 05 的导航接口和应用自有标识，不由手势模块直接操作另一套 History API。
- 图片和长图模式更新只改变当前预览会话，不堆叠历史记录；保持底层页面访问 ID 和预览 ID 的稳定引用。
- 不增加自由或双指缩放，不将手机浏览器模拟结果当作真机结论。

## 验收条件

- [ ] 长图默认完整显示，并可切换为适应宽度后纵向阅读；显示模式操作也可用键盘完成。
- [ ] 切换图片重置长图纵向位置；横向滑动切图遵守首尾不循环和单图规则。
- [ ] 纵向长图阅读不会误触发横向切图或滚动底层页面，横向操作不破坏页面滚动锁定及关闭后的恢复。
- [ ] 手机浏览器返回优先关闭当前预览；按钮、Esc 和后退不会发生双重撤销，也不盲目后退到站外。
- [ ] 从列表与详情分别打开、切图、关闭后，浏览器前进恢复同一预览及本会话最后查看的图片；再次后退只关闭该预览。
- [ ] 关闭后保留仍可前进到达的预览状态；开始新导航分支后不虚构已被浏览器丢弃的前进记录。
- [ ] 重复打开/关闭预览、替换历史元数据及连续历史操作不会重建底层页面或覆盖其阅读快照，不依赖路由 key 在替换时保持不变。
- [ ] 预览中刷新或遇到遗留标记但内存不存在时，用替换导航清理失效状态并显示底层页面；不自动连续后退，不出现循环或空弹层。
- [ ] 每种关闭路径都恢复底层位置和合理焦点，失败图片仍可关闭或切换，滚动锁不会残留。
- [ ] Playwright 覆盖列表/详情入口、前进后退、刷新、失效标记和多次开关；单图、首尾和长图样例都进入验证。
- [ ] 在约定手机宽度及桌面宽度验证布局与键盘；移动端手势验证记录实际设备/浏览器或模拟方式，缺少真机时明确未验证范围。
- [ ] 本票测试、类型检查、构建及既有测试通过，05 的基本图片浏览保持正常。

## 本票边界

本票完成图片预览及其历史行为，不实现评论读取或每次详情访问的完整评论快照。图文、评论和楼中楼一起使用时的跨模块恢复由 07 承担，跨设备总体验收由 09 汇总。
