# 01：打开动态列表并进入文字详情

Status: ready-for-agent
Blocked by: 无（可立即开始）

**交付行为：** 用户打开页面即可看到固定 UP 主及首批文字动态，进入某条详情阅读完整正文，再返回列表；直接访问、内容不存在和首次读取失败均有可理解的结果。这条可运行流程同时建立最小工程与测试支撑，而不是仅交付脚手架。

## 依据与范围

- [实施规格](../spec.md)：用户故事 1、2、5、6、8、10–12、40、41、43、44、48、49、52–54、56；本票仅承担其中的文字浏览与基础装配部分。
- [SRS](../../../docs/SRS.md)：FR-01、FR-02、FR-03、FR-04、FR-05、FR-11、FR-12、FR-13、DR-01、DR-02、NFR-01、NFR-02、NFR-04、NFR-05。
- [HLD](../../../docs/HLD.md)：第 1–6、9、10 节。重点是模块职责、展示模型、读取结果语义、稳定会话容器与导航身份。
- 验收关联：AC-01、AC-02、AC-03、AC-04、AC-13、AC-14、AC-15、AC-18 的文字/基础导航部分，以及 AC-19 的可构建部分；引用不表示整项在本票完成。

## 实施约束

- 按 HLD 初始化单工程，固定兼容依赖，使用 nvm、pnpm、React、TypeScript、Vite、React Router、CSS Modules。建立 Vitest、React Testing Library 和 Playwright 的最小可执行测试路径，不引入真实服务或额外状态库。
- 通过统一异步读取接口装配正常及可控模拟 Adapter；先实现本票用到的列表和详情读取。使用字符串 ID、明确时区、缺失空值和安全文本，不让页面直接读取原始模拟集合。
- 会话 Provider 保持稳定挂载，导航保留应用自有的页面访问标识和有效来源关系，为后续快照恢复提供基础；不预做评论状态、图片历史或整套恢复逻辑。

## 验收条件

- [ ] 打开列表显示头像、昵称、首批最多 10 条按时间倒序的文字动态及对应字段；无简介、充电标识、关注入口或真实写操作。
- [ ] 通过“查看详情”进入对应完整正文并定位顶部；正文选择、头像和昵称不触发意外导航，卡片不整体绑定跳转。
- [ ] 有有效列表来源时可返回列表；直接打开详情且无有效站内来源时，页面返回入口回列表首页，不盲目后退离站。
- [ ] 按 HLD 的路由方案可直接打开或刷新有效详情；本票验证开发/测试服务器流程，Nginx 回退验证留给 08。
- [ ] 时间按北京时间显示为 `YYYY-MM-DD HH:mm:ss`，计数不缩写；计数零值与缺失值不同，默认头像、未知用户和无效时间等按 FR-12 展示。
- [ ] 详情正文保留换行、emoji，URL、话题和提及为普通文本；HTML/脚本样例不被执行。正文与图片均为空的样例显示规定兜底，不猜测已删除。
- [ ] 列表和详情首次读取有加载状态；空列表是成功空态，失败可在对应区域重试。取消或过期详情读取不覆盖当前选择，也不显示为用户错误。
- [ ] 不存在的动态 ID、未知页面路径、普通读取失败分别展示，均提供符合场景的返回或重试入口。
- [ ] 正常与故障装配可以确定性切换供开发/测试使用，正常页面不暴露故障按钮或公开故障参数，不请求真实 B站或依赖后端及凭据。
- [ ] 本票页面在手机单列和桌面下可操作；长昵称不撑宽页面，主要操作可聚焦、焦点可见，触控区域符合 SRS。
- [ ] 公开行为测试覆盖字段展示、时区、空态、错误分类与重试；浏览器测试打通“列表 → 文字详情 → 返回”及有效详情直达。
- [ ] 类型检查、相关测试及静态构建可运行并通过，固定依赖和运行方式可复现；检查未执行时如实说明，不当作通过。

## 本票边界

动态追加、列表正文折叠和列表位置恢复归 02；评论数在本票只展示，评论定位与内容归 03；楼中楼归 04；内容图片归 05/06；完整详情历史恢复归 07；Nginx 配置与正式交付验证归 08/09。后续需求暂未完成不等于本票可宣称整个 FR-01、FR-02、FR-03 或 FR-10 已满足。
