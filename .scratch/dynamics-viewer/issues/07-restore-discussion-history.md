# 07：在历史访问中继续阅读评论与回复

Status: ready-for-agent
Implementation: completed（见 [07 验收记录](../acceptance-07.md)；此 Status 保留分诊标签，不表示实施进度）
Blocked by: [04：展开、收起并继续阅读楼中楼](04-expand-comment-replies.md)、[06：在手机上阅读长图并安全使用返回操作](06-mobile-image-history.md)

**交付行为：** 用户往返不同详情或同一动态的多次访问时，恢复那一次的评论排序、加载进度、回复与阅读位置；中途看图、异步读取和屏幕变化不会打断阅读进度。

## 依据与范围

- [实施规格](../spec.md)：用户故事 7、17、18、24、33、37–42、45、46、50、51 的跨模块恢复部分。
- [SRS](../../../docs/SRS.md)：FR-02、FR-06、FR-07、FR-09、FR-10、FR-11、NFR-01、NFR-02、NFR-03。
- [HLD](../../../docs/HLD.md)：第 4–8、10 节。重点是访问快照隔离、请求生命周期、入口优先级、锚点恢复及预览复用底层状态。
- 验收关联：AC-12，并整合 AC-02、AC-07、AC-08、AC-11、AC-14 的相关状态组合，为 AC-20 提供完整恢复行为。

## 实施约束

- 复用前置票的导航、会话、评论和预览能力，不再引入第二套历史栈、查询缓存库或持久化恢复机制。
- 只共享不可变内容实体，不共享不同访问的可变排序、分页及展开状态；恢复以页面访问 ID 为单位，而不是动态 ID。
- 02 的列表恢复通过 06 的传递依赖已经具备，不重复添加依赖；评论及预览都已可独立使用，本票聚焦二者组合和详情快照。

## 验收条件

- [x] 在详情加载多批评论并展开回复后离开，历史返回恢复该次访问的排序、已加载顺序/范围、回复及文字展开状态、下一批进度和位置。
- [x] 同一动态先后两次访问采用不同排序与位置，前进后退分别恢复对应快照；一份视图状态的修改不覆盖另一访问。
- [x] 从详情返回列表仍保留原列表进度与展开状态，加入图片和楼中楼后不回归 02 的行为。
- [x] 主动“查看详情”定位顶部，主动“评论数”定位评论区；历史导航才使用旧阅读位置，入口优先级不会被迟到恢复覆盖。
- [x] 阅读评论/回复时打开并关闭图片预览，底层快照、读取代次和加载进度不重置；预览新增历史记录不被误判为新的页面访问。
- [x] 请求未完成就离开再返回时，可从成功内容继续读取未完成批次，不能保持永久加载、跳过数据或把取消显示成错误。
- [x] 不同访问及不同排序的旧成功、旧错误和旧完成回调都不污染当前状态；单条回复读取不会无故使其他区域失效。
- [x] 恢复先还原数据与展开范围，再按稳定动态/评论/回复标识及偏移定位；锚点缺失时像素后备被限制在有效范围，过程有限结束。
- [x] 图片慢加载、未知尺寸或视口变化后仍恢复到合理阅读内容；无需等待无关图片全部下载，也不通过无限修正滚动制造抖动。
- [x] 用户主动滚动后旧恢复任务停止抢占；焦点恢复不额外覆盖位置，预览锁定解除后页面可继续正常滚动。
- [x] 刷新允许重置状态但有效详情仍可读取；无有效列表来源时页面返回回到列表；不写入本地或会话存储。
- [x] 浏览器自动化覆盖不同访问快照、列表与详情双向恢复、评论/回复/预览组合及加载中离开；可控 Adapter 验证上述异步竞争。
- [x] 本票测试、类型检查、构建及既有测试通过；浏览器环境、恢复误差问题或未验证组合如实记录，不以单一像素值断言替代实际可见内容检查。

## 本票边界

本票不新增阅读历史产品入口、不持久化进度、不做后台刷新或跨标签页同步。预览自身完整行为已由 05/06 承担，本票不重新实现；静态托管由 08 完成，所有环境及验收项由 09 汇总。
