Status: ready-for-agent

依据：[FSR](../../docs/FSR.md)、[SRS](../../docs/SRS.md)、[HLD](../../docs/HLD.md)。整理基线为已确认文档提交 `e3a2064`。

任务 01–09 的实施及已确认本期范围内验收已完成，当前结果见 [任务 09](issues/09-cross-device-acceptance.md) 与 [09 验收记录](acceptance-09.md) 第 13 节。`ready-for-agent` 保留为规格的分诊状态，不表示仍待实施，也不代替下方完成判定与验收证据。

## 问题陈述

个人查看者希望在桌面或手机上，集中阅读一个固定 B站 UP 主的图文动态及评论。查看过程需要方便地进入详情、浏览多图和长图、阅读一级评论及楼中楼，再回到原先的阅读位置，而不是使用包含大量无关导航与推荐内容的完整站点界面。

本期真实数据采集与服务端尚不接入，因此应先使用模拟数据验证完整的只读浏览体验。未来上游取得的内容虽然属于 B站充电动态，在本系统内仍统一视为普通动态；“充电”不构成本期展示或权限规则。

## 解决方案

建设一个单工程、浅色主题的响应式静态前端，提供动态列表、独立详情、评论阅读及图片预览。以可替换的异步数据读取接口连接本地模拟实现，使正常、空态、失败重试和异步竞争均可独立验证。

沿用 HLD 的模块、会话状态和历史导航设计：内容按稳定标识引用，每次页面访问保存自己的阅读快照；图片预览具有独立的临时历史记录；历史返回恢复原访问，主动入口遵守指定定位。通过公开行为测试与真实浏览器验证保护这些交互，而不是只交付正常状态的效果图。

未来图片由后端返回自有 OSS 的 URL，浏览器直接请求；本期使用合法的项目内演示素材，保留缩略图、预览图和尺寸信息。交付可构建的静态产物及 Nginx 部署说明，不实施真实后端或云资源配置。

4. 作为个人查看者，我希望较长的列表正文可以展开和收起，以便在快速浏览与完整阅读之间切换。（FR-03）

6. 作为个人查看者，我希望通过“查看详情”进入动态顶部，以便从头阅读完整内容。（FR-02、FR-10）

## 实施决定

### 1. 工程与模块

采用已确认的 React、TypeScript、Vite、React Router 单工程方案；使用 CSS Modules 与 CSS 变量，不引入大型全站 UI 框架、Tailwind、额外状态管理或数据缓存库。依赖版本在初始化时核对兼容性并固定，使用 nvm 和 pnpm。

模块职责沿用 HLD 第 2 节：应用导航、会话状态、动态浏览、评论阅读、图片预览和数据读取。复杂行为封装在模块公开接口之后；副作用协调与 reducer 的纯状态转换分开，不为将来可能的复用建设空转发层或多包工程。（NFR-05）

### 2. 页面与阅读交互

实现列表和独立详情，页面信息、正文折叠、图片网格、评论及回复行为严格引用 FR-01 至 FR-09。身份信息不含 UP 主简介，动态没有充电专属标识；评论点赞数只读，文本链接及提及不产生额外导航。

采用 HLD 第 6 节确定的列表与按动态标识访问的详情路由；URL 表达页面身份，不表达评论排序、展开进度或预览位置。所有入口和无效地址遵守 FR-02、FR-13，不将整张卡片设置为跳转区域。（FR-01、FR-02、FR-03、FR-08、FR-13）

### 3. 展示数据与异步读取接口

实现动态列表、详情、一级评论、楼中楼四类异步读取能力。本期装配正常模拟 Adapter，开发与测试装配可控 Adapter，未来 API Adapter 仅保留替换位置，本期不实现。

字段及结果语义采用 HLD 第 3 节：字符串稳定 ID、明确时区的时间、空值保留、不可变内容对象，以及成功、成功空结果、动态不存在、读取失败和取消的区分。正文安全渲染；最终时间与计数展示依 FR-04、FR-12。UI 不导入原始模拟集合，也不解释未来协议。（DR-01、DR-02、FR-04、FR-12、NFR-04）

### 4. 排序、分页与回复范围

读取 Adapter 对完整集合排序后分页，页大小、回复预览量及追加量以 FR-05、FR-06、FR-07 为准。空排序字段及并列 ID 比较沿用 HLD 第 3.1 节。

分页结果提供数据与不透明的下一批标记；调用方原样传递，不计算后端页码，也不维护相冲突的结束标志。只有被接受的成功结果才能推进标记，失败重试同一批次，追加按稳定 ID 保持无重复及顺序正确。收起回复改变可见范围，不丢弃已经成功读取的内容。（FR-05、FR-06、FR-07、DR-02）

### 5. 局部加载与请求竞态

每个读取区域维护独立的首次/追加状态及失败操作上下文。请求关联访问、资源、父级、排序、批次和代次；同时使用尽量取消与强制有效性检查。

过期成功、过期失败和完成回调均不能污染当前状态；同批次请求在协调逻辑和界面两层去重。排序切换只重置评论阅读状态，不清除动态内容。离开后返回不能留下无法结束的加载标记；取消不作为用户错误提示。具体流程沿用 HLD 第 4 节。（FR-06、FR-11）

### 6. 会话状态与访问快照

使用稳定挂载的 Context + reducer 保存当前标签页内存状态。内容可按 ID 共享引用，但每次主动访问拥有独立的阅读快照；历史导航恢复对应访问，不恢复该动态的最后一次全局状态。

不使用本地或会话存储持久化阅读进度；历史 state 仅含轻量导航元数据。Provider 不随路由 key 或预览变化重建，快照不得共享会被其他访问原地修改的视图状态。共享内容、请求运行状态和快照职责沿用 HLD 第 5 节。（FR-10、NFR-03）

### 7. 导航、预览与恢复

应用导航统一处理主动进入、历史导航和预览关闭。底层页面访问标识与预览标识分离，不依赖路由 key 跨替换操作保持稳定。

打开预览新增同 URL 历史记录，切图不堆叠记录；关闭只撤销有效的预览记录，历史后退已完成撤销时不得再次后退。前进可恢复保留的预览内存；刷新时清理失效标记，正常显示底层页面。具体来源校验、替换降级及焦点规则沿用 HLD 第 6、7 节。（FR-02、FR-09、FR-10、NFR-02）

位置恢复采用稳定内容定位点及视口偏移，像素位置作后备；先恢复内容范围与展开，再定位。主动入口优先于旧位置，用户主动滚动优先于迟到的恢复任务。由应用统一执行手动恢复，不叠加路由库内建滚动恢复或其持久化机制。（FR-10；HLD 第 8 节）

### 8. 图片、样式与布局

图片模型沿用缩略 URL、预览 URL、顺序及可用宽高。本期准备真正的缩略素材，列表懒加载、预览按需加载，尺寸信息帮助预留布局空间。展示层不改写来源 URL 或签名参数；坏图重试局部处理，不影响预览关闭或切图。（FR-08、FR-09、FR-11、DR-03、NFR-03）

CSS Modules 隔离样式，CSS 变量统一基本视觉值，Grid/Flex 实现约定布局。正文以实际渲染行数判断折叠；视口、焦点、触控和安全文本展示采用 SRS 标准。只提取实际重复的基础元素，不增加通用设计系统。（FR-03、NFR-01、NFR-02、NFR-04；HLD 第 9 节）

### 9. 模拟样例与装配隔离

以 SRS 第 8 节作为验收数据集基线：至少 25 条动态、某条动态下 45 条一级评论、某条评论下 25 条回复，并覆盖全部内容边界及局部失败。正常数据与缺失字段、失败、乱序返回场景可分开装配。

测试以明确操作控制异步结果，不以随机延迟或故障代替可重复验证。正常发布版本无公开故障开关，不依赖真实 B站、API、数据库或 OSS 凭据。（DR-01、DR-02、NFR-04）

### 10. 构建与静态交付

本地或 CI 执行检查、测试与构建，产物由 Nginx 静态托管。页面入口重新验证、带哈希资源长期缓存、演示图片采用版本化或合适缓存，页面回退与缺失静态资源错误分别处理。

交付配置示例和验证步骤，不实际安装或配置云服务。目标主机为 2 核 2GB，但不承诺未经测量的容量；未来图片经 OSS 直接交付，后端、数据库及爬虫资源需另行评估。（NFR-05；HLD 第 11 节）

## 测试决定

### 已确认的测试接缝

用户已确认 HLD 第 10 节的测试设计，并在本次指令中要求沿用，不引入新的测试接缝。

主要可替换接缝是统一数据读取接口：同一页面与模块可装配正常模拟或可控 Adapter。业务测试从界面或模块公开操作进入，断言用户可观察结果；浏览器测试从公开页面、URL 和导航操作进入。无需为每个组件、私有函数或内部 Hook 建立测试专用接口。

一个有效测试应在行为违反需求时失败，并允许内部组件拆分、文件移动或 reducer 重构而不无故失败。接口调用计数只用于验证明确的去重与不重复读取契约，不将实现步骤顺序普遍固定为测试预期。

### 工具与被测模块

| 测试方式 | 被测模块与行为 | 主要替换或控制方式 |
| --- | --- | --- |

当前仓库尚无产品应用工程或已有业务测试套件，没有可复用的组件测试、读取实现或历史恢复实现。HLD 确认的接口与测试组合是本次实施基线，不应把官方文档示例描述成仓库中已经验证的先例。

不为不存在的旧应用安排预重构；随着可独立演示的行为切片建立最小工程和测试支撑。依赖版本、测试环境配置和具体文件组织在实施时固定，不在本规格中假定已经存在。

## 范围排除

沿用 SRS 第 1.3 节，本规格不引入以下工作：

- B站接口、爬虫、数据库、真实后端或模拟 HTTP 服务；真实 API 协议与服务端分页设计。
- 登录、权限、多用户、充电标识、购买、解锁和会员体系。
- 多 UP 主、简介、粉丝数、关注、独立个人主页、搜索筛选与统计。
- 视频、转发动态、评论图片、复杂表情包、专用富文本和真实写操作。
- 图片下载、画布处理、自由/双指缩放，深色模式、主题设置和离线支持。
- 持久化阅读历史、跨标签页同步、后台自动刷新及无限历史容量承诺。
- OSS 上传与配置、签名刷新、CDN、真实站点访问保护、云服务器实际配置或新的 CI 平台接入。
- 多包仓库、通用组件库、复杂数据清洗框架，以及替代 HLD 已确认方案的额外状态或缓存库。
- 大型压测、未经验证的性能指标、付费采购、硬性上线日期。

本次文档任务也不包含任务拆分、工程初始化、依赖安装、代码实现或自动提交与推送。
