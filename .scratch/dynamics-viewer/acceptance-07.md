## 实施与恢复顺序

1. 沿用会话 reducer 的 `pageEntryId`，新增 `DetailSnapshot`：成功详情内容、当前评论排序、已加载顺序与下一批标记、评论文字展开、各根评论的回复读取/可见范围/文字展开、阅读位置。不同访问不共享可变视图状态；每次提交只替换草稿对象，不修改已保存快照。
2. 详情按访问 ID 挂载。成功内容从所属访问初始化，评论和回复同步还原已读数据及展开范围，然后复用最多两个布局帧的锚点恢复。动态、评论、回复使用带种类前缀的稳定标识；回复标识还包含根评论 ID。
3. 控制器和运行中请求不进入快照。未完成首批或追加返回时重新读取原 cursor，保留成功内容；成功快照不重复读取，局部错误仍可原区原批重试。访问/排序卸载中止旧请求，旧成功、错误、拒绝及完成均不能覆盖返回后仍在读取的区域。
4. 主动入口沿用顶部/评论区意图；只有挂载时已有历史快照才恢复旧位置。同一挂载期间写入的临时快照不能改变入口判断。预览保持底层挂载及访问 ID，不重建读取代次，也不取消评论/回复请求。
5. 复用 02/05/06 的锚点、未知图片稳定占位、预览解锁和 `preventScroll` 焦点恢复。不新增历史栈、缓存库、存储恢复、后台刷新或阅读历史入口。

为真实覆盖图片与讨论组合，首条有 45 条评论/25 条回复的虚构动态复用一张已有未知尺寸图片（自然比例与默认占位不同）；没有增加素材下载或外部服务。既有头像点击测试改用明确头像名称，并把新增图片按钮纳入键盘顺序断言。专用 fault Adapter 增加讨论第二批 1500ms 延迟，供浏览器观察确实处于加载中的离开；生产装配仍无故障计划。

### Standards

只读review确认0硬违规，提出4项非阻断启发式判断：快照构造/重置分散（可能Shotgun Surgery/Feature Envy）、三处初始读取字面量重复、评论/回复草稿提交形状重复、锚点字符串Primitive Obsession。按职责保留：详情负责初始访问，评论负责排序重置，回复负责根节点草稿；三处短初始值不值得增加工厂；两种草稿更新范围不同，不为相似提交形状创建通用Hook；既有定位接口使用DOM字符串标识，本票增加种类/根节点前缀以隔离。没有增加抽象来提前满足未来需求。另有2处README标点前空格已修正，不属于工具或架构违规。标准轴最主要的保留判断是快照字段变更可能牵动多个拥有者，不将其当成确认缺陷。

### Spec

只读review确认核心恢复要求已落实，提出2项非确认风险和1项范围疑问：恢复完成后再改变视口未专门覆盖；若正文未成功就离开，返回时尚无内容可重锚；首条生产演示动态新增图片是否越界。分别处理：HLD要求恢复有限结束、完成后停止纠正，保持最多两帧而不常驻resize滚动修正，该额外组合明确未验证；正文未成功时只有页面骨架而无已读正文/评论稳定锚点，保留有界像素后备并正常重新读取，不把失败/未完成结果缓存为成功，该组合未增加专门浏览器用例；演示图片属于完成07要求的正常浏览器讨论/预览/慢图组合所需素材，复用现有资源且不改变05/06实现，不是新增产品能力，必要的头像/键盘断言随素材同步。无需实现08/09来处理这些疑问。Spec轴0未处理确认缺陷，0未要求的产品能力；最主要保留风险是未穷举所有视口变化时机。

## 未验证与范围边界

- 本票仅验证桌面 Chromium 与 Pixel 7 模拟视口；没有 Android/iOS真机、Safari/Edge、系统返回手势、软键盘、屏幕阅读器或所有方向/缩放组合验收。跨设备交付由09汇总。
- 恢复完成后再改变视口未增加单独专项，也没有正文尚未成功就离开再返回的专门浏览器用例；恢复有限结束，不常驻追逐所有后续布局变化。尚无成功正文时没有已读内容锚点，采用有界后备并重新读取，不声称该额外组合已经独立浏览器验证。
- 新增主动输入中断专项是wheel；触摸/键盘/指针中断沿用既有实现，不宣称本票穷举这些输入与每种异步/预览组合。组合恢复测试检查实际可见内容，位置误差仅辅助；不同字体、DPR和真实设备仍可能产生误差。
- 缺失锚点的有界后备由DOM输入模拟；没有声称当前不可变演示数据会自行删除历史评论。未枚举每一种任意失效History元数据形状。
- 正常静态产物不包含故障计划；“观察加载提示后离开”的浏览器证据来自独立fault开发装配，正常静态流程验证其余组合，异步竞争由可控Adapter验证。慢图场景通过图片网络边界阻塞，不是假延迟UI。
- 会话内保留访问/预览可能增加内存使用，未做无限历史容量、长期内存/性能压力或真实OSS签名过期验证。不持久化、不后台刷新、不跨标签页同步；刷新重置被允许。
- 没有Nginx配置、资源缓存/404、部署或云环境验收；Vite preview不代表08完成，也不代表全部AC-20跨设备验收完成。
- 在当前分支提交，暂不推送。
