# 01：阅读页统一排版、用语与紧凑 UP 选择条

Status: resolved
Blocked by: None

依据：[实施规格](../spec.md)。覆盖 UI-01、UI-02、UI-03、UI-12 的阅读部分。

## 交付内容

从全部动态或单 UP 列表进入阅读时，公共顶栏与管理入口消失，界面使用统一的“动态”用语和排版；头像选择条完整展示长昵称但不留下由屏幕外内容撑出的空白。建立后续管理排版可复用的主题标尺，不另建控件库。

## 验收条件

- [x] 应用生成的阅读/管理文案、无障碍名称与空错提示按语义改名；源正文、昵称和技术标识保持原样。
- [x] 所有阅读页无公共品牌/导航/管理跳转；管理独立入口及自身导航仍可用，不能用去入口代替鉴权。
- [x] “全部动态”及 UP 项为上图下字，48px 同宽、12px 完整换行；隐藏横向滚动条，触屏、触控板和键盘均可访问。
- [x] 可读的可见昵称至首卡约 12px；屏幕外长昵称不撑高整排，滑到长昵称时能读完整；选项点击与横滑不误进动态。
- [x] 阅读正文、评论、作者、元信息、链接、徽标按正式标尺显示；回复详情 `‹ 评论详情` 与普通阅读返回链接采用14px/22px、常规字重和至少44px点击区；会话页的同款复核由06完成，不提前添加空页面。
- [x] 正文色 #30383d、辅助文字色 #65727a、操作色 #287f8f；13px时间/计数不沿用低对比浅灰。主栏约724px、卡内距手机16px/桌面24px、卡片间距手机12px/桌面16px，左右边缘对齐。
- [x] 原有 6 行折叠按新行高重新验证，完整正文与图片行为不被删减。
- [x] 主要触控区域至少 44px；普通排序/返回字号不靠大按钮边框放大；360/390/768/1280px 无整页横溢出。
- [x] 对正式组件做可观察布局与文案检查，保留管理业务及现有阅读导航回归；截图记录变更原因，不自动宣告新视觉已签收。

## 边界

本票不改变默认排序，不补桌面列表内评论或正文新标签；局部详情页头与返回语义由 04 收口。管理按钮缩小和手机输入字号由 08 使用本票标尺交付。原型工具栏及示意图片不进入生产。
