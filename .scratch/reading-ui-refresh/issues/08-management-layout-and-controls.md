# 08：管理排版、右侧启停与紧凑按钮

Status: resolved
Blocked by: 01

依据：[实施规格](../spec.md)。覆盖 UI-01 的管理复核、UI-12 的管理部分、UI-13、UI-14 的自动化部分。

## 交付内容

两级管理页使用统一排版，单 UP 状态行左侧显示状态、右侧放启停或重新添加；按钮视觉更小，手机输入仍舒适，且原有管理业务完整保留。

## 验收条件

- [x] 管理列表继续仅显示身份与状态，不新增列表启停；单 UP 的启用/停止/重新添加在同一控制行右对齐。
- [x] 手机按钮为适宽右对齐，不占满整行；长昵称、UID、反馈和按钮文案可换行或自然增宽，不遮挡其他信息。
- [x] 操作按钮文字13px，桌面视觉约32px高、手机约36px高，四字按钮约76px宽；实际点击区至少44px且不覆盖相邻操作。
- [x] 管理标题、区块标题、状态/说明和表单标签按统一标尺显示，复用01的颜色与卡片标尺，管理分区间距手机约20px/桌面约24px；主要说明不再压成低对比的13px长段落。
- [x] 手机输入类控件16px、桌面14px，输入高度约44px；局部配置不把普通按钮字号一起放大。需要库内部覆盖时登记原因并补稳定的外部行为断言。
- [x] 启停只提交已保存配置，保存草稿不隐式启停；重新添加、重复提交、过期请求和失败草稿保留等原语义继续成立。
- [x] 删除配置仍与日常启停分区并确认，保留已保存内容；UID新增、模式、数量、指定目标、检查/同步状态、通知选项、错误与重试不因原型未画全而被删除。
- [x] 真实管理 API 替身/隔离 API 回归与四宽度检查通过，记录计算字号、实际点击尺寸和右边缘对齐，而不是只更新截图。
- [x] 生成新管理候选截图，明确手机输入的 Safari 聚焦/失焦仍待 10 真机验证；不提前关闭原已知限制。

## 依赖理由

01 先交付可复用主题标尺与应用文案边界。本票在该标尺上完成管理操作的完整用户路径，不另写一套并行视觉体系。

## Answer

已交付：管理两级页面用 01 的标尺统一排版——页标题 18/20、区块标题 16/24 600、状态/说明/表单标签
14/22、操作按钮 13/20、昵称 16/24 600、徽标 12/20；卡片内距取 16/24 token、列表间距取 12/16 token、
管理分区间距手机 20px / 桌面 24px；长中文说明不再是 13px 淡字，颜色与卡片仍取 01 的 token。

单 UP 控制行改成状态在左、操作在右，按钮贴住卡片内容盒右边缘（四宽度实测右边缘差 0），手机不再占满整行，
长昵称/UID/反馈继续换行。启停、重新添加、保存、删除、新增 UP、目标增删与重试按钮统一：文字 13px，
可见高度桌面 32px / 手机 36px，四字按钮 76px，实际点击区 44px——按钮本体保留 44px 命中盒，
用 `::before` 的 inset（桌面 6 / 手机 4）画可见描边与底色，悬停/按下/禁用同块，相邻操作点击盒实测不重叠；
视觉块外的点击盒边缘仍命中同一按钮并只提交一次启停。

手机输入类控件 16px、桌面 14px，控件高 44px；只覆盖管理页输入行的库内部类 `.el-input__inner`，
`--el-font-size-base` 仍为 14px，普通按钮不跟着放大。原 `SIGNED_FONT_SIZE=14` 断言改为“手机 16 / 桌面 14 /
基础字号仍 14”，并补按钮 13px 的断言。

语义未变：启停只提交已保存配置（先改草稿再启停，提交的仍是已保存 N）、保存草稿不隐式启停、
重新添加、删除独立分区、防重、过期回调隔离、失败保留草稿与反馈、UID 新增、模式/数量、指定目标、
检查与发现状态、通知三态、错误重试与 401 固定提示均保持，既有用例未删改。

验证：`pnpm check`（27 文件 309 例 + e2e 项目守卫）、`pnpm check:dist`、管理页 e2e 四视口（mock 装配
30 passed）、实际 API + 隔离 SQLite 8 passed（含新增一例“启停只用已保存配置”）、四宽度视觉审计
6 passed。四宽度实测：按钮字号 13px、视觉/点击 36·44（手机）与 32·44（桌面）、四字按钮 76px、
输入 16px/44（手机）与 14px/44（桌面）、右边缘差 0。候选截图 63 张写入临时目录并用
`visual:diff-report` 记录差异；黄金图未更新。未验证：真实 iPhone Safari 聚焦/失焦与页面缩放（留给 10，
原已知限制未关闭）、视觉签收、真机与部署；4318/4319/4320 上的完整主 e2e 归 03，本票按受影响子集在
自配独占端口运行。

证据与限制见 [08 证据](../evidence/08-management-layout-and-controls.md)。
