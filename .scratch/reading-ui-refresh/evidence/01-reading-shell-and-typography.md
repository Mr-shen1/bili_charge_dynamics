## 2. 交付内容

**阅读壳（UI-02）**：`App.vue` 删掉公共品牌、主导航与“图片自检”入口，阅读页只剩主栏与唯一预览宿主；
非生产装配标识改为固定角标（调试标记，不是品牌或导航）。管理页仍由独立 `/manage` 进入并保留自己的页头与
“返回阅读”入口——去掉入口不是鉴权措施。mock/fault 装配的自检页自带 `自检导航`，不把调试入口塞回阅读页。

**用语（UI-01）**：应用生成的可见文案、无障碍名称与空错提示统一把阅读范围叫“动态”
（`全部动态`、`动态范围`、`UP {id} 动态`、`返回动态列表`），动作按语义改写
（`评论尚未保存`、`回复尚未保存`、`已保存 x/y`、`已保存的动态保留`）；管理页的发现、检查、目标移除与
删除配置说明同步复核。源正文、昵称、API 路径、DTO 字段与代码标识未改。

**UP 选择条（UI-03）**：`ArchiveNavigation.vue` 改为上图下字——图标/头像 48px，昵称容器同宽 48px、
12/18 完整换行，整块可点、选中态保持青色；隐藏横向滚动条（`scrollbar-width: none` + `::-webkit-scrollbar`），
键盘 Tab 可逐个到达。这一排高度只按**当前可见项**计算：屏幕外选项的昵称收成一行（文字仍在可访问树里，
链接名称不变），滑入视口即恢复完整换行，因此既不留整排空白也不裁字。可见昵称底部到首卡约 12px。

**排版标尺（UI-12 阅读部分）**：`theme.css` 交付一套 token（字号/行高成对、正文 `#30383d`、辅助文字
`#65727a`、操作色 `#287f8f`、主栏 724px、卡片内距手机 16/桌面 24、卡片间距手机 12/桌面 16），
并落到动态卡片、正文折叠、详情返回、楼中楼、回复区与窄屏回复预览：正文 16/28、作者 16/24、
评论/回复正文 15/26、昵称 14/22、时间计数 13/20、徽标 12/20；返回控件（`返回列表`、`‹ 评论详情`）
统一 14/22、常规字重、点击区 ≥44px。6 行折叠按新行高重新验证为 168px。

## 3. 关键取舍

1. **标尺以 CSS 变量交付**，不在本票另建控件库；02 落地“评论 N”14px 与排序单按钮的 13px/44px，
   本票按同一标尺调整评论条目的昵称 14/22、正文 15/26、时间计数 13/20（只改样式，不动 02 的区域身份
   与排序逻辑）。管理区块排版与手机输入字号归 08，本票未动 `--el-font-size-base`
   （`SIGNED_FONT_SIZE=14` 断言仍成立）。
2. **UP 条高度用“可见项测量”而不是固定上限**：固定高度要么裁字、要么留白，二者都违反设计要求；
   收成一行 + 滑入恢复是唯一同时满足“紧凑”和“完整可读”的写法，代价是 1 帧内的行高变化。
3. **图片上传状态文案保留**（`图片待归档`、`图片归档失败`、`归档图片地址不可用`、`评论图片待归档`）：
   它们描述媒体归档状态，不是阅读范围命名，机械改成“动态”会让状态语义失真。
4. **详情页头结构不动**：`动态详情` 标题与 `返回列表` 按钮的去留属于 04，本票只按标尺调字号与点击区；
   `‹ 评论详情` 的定位与样式留给 06 的会话页复用同一形状。
5. **导航恢复用例改用现有站内入口**：顶栏删除后详情页不再有“回列表”的品牌链接，两处 e2e 恢复用例
   改成“浏览器后退 + UP 条”作为同会话列表入口（不用 `page.goto`，否则会丢掉会话内快照语义），
   并用 DOM 点击避免浏览器把链接滚进视口、把离开位置记成 0。
6. **`UP 列表` 断言改成精确匹配**：单 UP 页同时有面包屑“UP 列表”与兜底链接“返回 UP 列表”，
   “未找到该 UP”分支下模糊匹配会两义报错（02 的整轮 e2e 也复现过同一盏红灯）。
7. **不动冻结件**：`frontend/tests/visual-baseline/` 黄金图未更新；`switch` 只更新了
   `tests/e2e-visual` 中因本票与 02 控件变化而失效的选择器与折叠行高断言。

## 6. 未验证与已知限制

- 真机（iPhone Safari 聚焦/放大、触屏横滑 UP 条与“滑动不误触链接”）、真实飞书深链接、部署与
  目标环境均未验证；本票只有 Linux 无头 Chromium 证据。
- 正式视觉未签收：黄金图仍是 14/17 的签收版本，`tests/visual-baseline/` 未更新；
  `pnpm visual:golden` 未运行，须由 10 在确认变化符合预期后执行。
- **预存缺陷（未在本票修）**：`frontend/scripts/compare-visual-baseline.mjs:151` 使用未定义的 `magick`
  ——只要出现超阈值差异，`pnpm visual:compare` 会以 `ReferenceError` 崩溃而不是输出逐张差异。
  本仓库当前候选必然出现差异，因此 09/10 在拿它做组合证据前需要先修（或另立 hotfix）。
- 本票不覆盖：详情页头与手机返回语义（04）、桌面卡片内评论（03）、手机回复排序（05）、
  会话页与入口（06/07）、管理启停右对齐与手机输入字号（08）；组合验证与四宽度正式截图归 09。
