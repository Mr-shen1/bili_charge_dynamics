## 1. 已确认决定

| 决定 | 内容 |
| --- | --- |
| 目标技术栈 | Vue 3 + TypeScript + Vite + Vue Router + Element Plus，继续静态 SPA 交付 |
| 重构方式 | 可全面重写框架相关实现，但保留经核实可复用的纯 TypeScript、数据契约和适配代码，不为重写而丢弃已有能力 |
| 功能边界 | 按固定代码基线保留现有业务、页面路径、后端 API、采集与归档逻辑，不按旧文档恢复或删除功能；图片展示/预览按第 4 节明确放宽 |
| UI 路线 | 一套自带样式的完整组件库；通用 UI 优先使用库，不另建全套基础组件库 |
| 状态 | 默认使用 Vue 响应式状态与 composables，必要时 provide/inject；不默认引入 Pinia、请求缓存框架 |
| 样式 | Element Plus 主题变量 + 少量局部 CSS；不引入 Tailwind，不同时维护多套样式体系 |
| 视觉 | 保留整体布局方向、品牌配色、内容层级及桌面/手机阅读体验；尺寸、间距、字体与控件外观允许重设，不再锁定旧像素值 |
| 发布 | 项目尚未正式全面使用；完整重构、验证后统一上线，不做页面级生产灰度或 React/Vue 混合运行 |
| 验收 | 自动化、四视口、Linux Chrome / iPhone Safari 实际验证、新版视觉确认及生产静态交付分别取证 |

本次没有新定义业务领域术语。沿用 SRS 中的动态、监控目标、归档、列表 scope、检查/同步、一级评论、回复和当前会话；框架、组件库与 composable 不写入业务术语表。

## 2. 现状与重构收益

当前前端已有生产归档 Adapter、独立 mock/故障装配、阅读与管理页面、窄屏独立楼中楼页、浏览器历史协调、图片预览以及自动化测试。回复已采用宽屏预览最多 3 条后页码每页 10 条、窄屏 UP 回复预览入口进入独立页的模型；动态及一级评论仍为 cursor 追加。可复用边界包括 `src/data/` 中框架无关的读取契约与映射，以及阅读快照、文本处理等纯 TypeScript；逐项以实施时的实时源码和测试核实，不按目录一律认定零耦合。

替代收益主要来自管理表单、通用控件、状态提示、图片加载展示与预览。阅读恢复、请求代次、分页、scope 隔离和管理写操作防重不是 UI 皮肤，不能因为引入组件库就删除。旧实现方式可以改变，但未经本次明确授权调整的用户可观察行为以代码基线为准。楼中楼页重新进入回到首屏、回复目标条件化前缀及已裁剪阅读信息均保留，不用“完善文档”顺带增加功能。

历史 #32 的自动化、#33 的设备验收和 #35 的视觉记录只描述各自版本与范围，不作为本次可直接继承的测试总数或通过结论。尤其不能把尚未完成的设备/视觉签收写成已通过。

## 3. 选型与目标边界

### 3.1 采用 Element Plus

采用 Element Plus 作为唯一 UI 库，主要依据是：

- 管理页所需的表单、输入、选择、按钮、提示和状态组件可直接使用。
- `el-image` / `el-image-viewer` 提供图片加载展示与预览能力，可通过公开属性、事件和应用控制的挂载衔接业务导航。
- 用户已接受组件库原生交互，不再要求为旧版网格、缩放参数、滑动切图或专门长图适宽逐项补齐自研实现。
- 主题与按需引入有官方支持，适合以库为主体而非以定制样式覆盖库内部结构。

Naive UI 是讨论过的替代，图片组受控状态也是可用方向，但本次不同时引入第二套 UI 库。PrimeVue 亦经过比较，本项目不采用；不依赖未锁定版本的许可或组件能力推断来证明本方案可运行。若 Element Plus 在关键验证门槛失败，回到选型讨论，而不是悄悄混入另一套库。

依赖版本、Vue/Vite/TypeScript/测试库兼容组合在实施时核实并写入 lockfile；本文不指定未经项目实跑验证的版本号，也不声称最新版一定兼容现有构建链。Node 使用 nvm，依赖和脚本只使用 pnpm。

### 3.2 模块与依赖方向

```text
Vue 页面 / Element Plus 组件
  ├─ 阅读、评论、管理 composables ──> 现有读取/管理契约 ──> API Adapter
  ├─ 应用会话：每次访问的快照、scope、分页与展开状态
  ├─ 唯一导航协调器 ──> Vue Router / 浏览器历史
  └─ 图片预览连接层 ──> Element Plus ImageViewer

装配：生产 API / 独立 mock / 开发故障入口分别注入
后端：FastAPI + SQLite + 独立 collector，保持不变
```

- 组件处理展示及用户意图，不解析 HTTP DTO、不自行拼接 OSS URL、不触发上游采集。
- composables 管理区域状态、副作用生命周期和公开操作；纯状态转换保持可独立测试，不将旧 hook 逐个机械改名。
- 会话状态在应用根部创建，生命周期高于路由页面；通过显式依赖注入共享，测试可创建独立实例。不以每次路由变化重建会话，也不默认使用跨测试共享的模块级可变单例。
- 内容实体、访问快照与请求运行态分开；列表/动态详情恢复各自状态，独立楼中楼页沿用当前不保存自身阅读快照的行为，不因框架迁移新增历史页码恢复。不把响应式代理写进 `history.state`。历史只保存应用命名空间中的可序列化轻量元数据，尊重 Vue Router 自有 state。
- 取消与代次校验并用；旧成功、失败及完成回调均不能改写新访问。管理写入仍防重复提交、隔离过期结果并保留失败草稿。
- 导航意图、预览历史和阅读位置由一个协调器负责。不能依赖 React Router 特有的 `location.key` 或动作 API，也不能让 Vue Router 自动滚动与应用锚点恢复同时工作。
- 默认使用 `.vue` 单文件组件与 Composition API；组件库之外只保留真实的业务组件，不把每个库按钮包装成无行为的一层转发。

### 3.3 替换与保留矩阵

| 区域 | 目标实现 | 仍需项目负责 |
| --- | --- | --- |
| 管理表单与操作反馈 | Element Plus 表单、输入、选择、按钮、提示等 | UID/ID 字符串规则、模式互斥、独立草稿、防重、错误语义、归档保留 |
| 状态、空态、加载、排序/分页控件 | 优先采用库组件 | 区分检查/同步、来源/本地计数、真实空/失败/未归档；根评论 cursor 追加与回复实时页码分开 |
| 动态、评论、回复及独立楼中楼页 | Vue 业务组件 + 库基础组件 + 局部布局 | 文本安全、当前折叠规则、作者身份、条件化回复目标、宽窄屏阅读差异、只读语义、事件隔离 |
| 缩略图与图片预览 | `el-image`、`el-image-viewer`；栅格或 CSS Grid 排列 | 图片组、状态与 URL 映射、导航连接、按需加载验证 |
| 路由、会话与阅读恢复 | Vue Router + 应用协调器/composables | 每次访问独立快照、scope 隔离、主动入口/历史返回区别、有界恢复 |
| 数据 Adapter 与确定性规则 | 经核实后复用纯 TypeScript | 现有 HTTP/DTO/cursor/取消契约；不可用时显式失败，不静默回退 mock |

动态列表与一级评论的“加载更多”仍使用不透明 cursor，不为控件改造协议；展开回复已有独立的实时页码接口，可用库分页控件对接，不从 cursor 推导页码。宽屏预览与回复页码不能合成旧 3/13/23/25 累计追加模型。保留窄屏独立楼中楼路由、进入首屏/返回详情的现有行为及条件化“回复 X:”前缀。UI 改版不恢复已取消的阅读页编辑时间、整块归档信息、统计面板或同步状态读取按钮，也不要求将全部后端 metadata 展示到页面。

## 4. 图片展示与预览：明确的需求例外

### 4.1 放宽项

图片展示/预览是本次“功能原则不变”的明确例外，已同步 SRS FR-08/09 及对应 AC：

- 缩略图列数、比例、列表显示数量不再固定为旧版四图两列、其他三列、九格上限。
- 缩放步长、倍率范围、旋转与工具栏形式不锁定旧实现，优先使用库的公开配置及原生能力。
- 移动端滑动切图、双指缩放与双击放大/还原按 SRS FR-09 由应用补一层薄手势（未放大时图片不可拖动），仍复用库的缩放、旋转与拖动引擎；不强制专门“长图适宽”、固定倍率/步长。
- 不为单张图工具栏、遮罩关闭等细节复刻旧版；按最终固定版本的公开能力选择配置，并记录新版行为。

这是采用原生组件的许可，不是允许删掉图片或把不可操作的预览当作通过。底线如下。

### 4.2 保留项

1. 图片不变形；预览能完整查看原图，长图内容可实际阅读。不强制使用旧版适宽/滚动实现。
2. 缩略图即便只显示部分，所属完整图片组仍可访问；保留顺序和当前图片对应关系。
3. 动态图片与每条一级评论图片分组，不串入其他 owner；不增加回复图片。
4. 区分服务端 pending/failed、地址不可用和浏览器加载失败。失败图片不能阻断查看其他图片或关闭；可重试的浏览器失败仍可局部重试，不调用采集/上传重试接口，不访问来源业务图。
5. 手机可以滑动切换、双指缩放与双击放大/还原当前图片并关闭（只缩放图片，不缩放页面；未放大时图片固定）；桌面保留键盘可操作性与清晰焦点，图片预览期间底层不被误操作或带动滚动。
6. 浏览器后退优先关闭预览，不离开底层页面；关闭后恢复底层位置与合理焦点。有效会话中的前进恢复语义继续遵守 HLD，刷新失效标记安全降级。
7. 业务图片原样使用后端公开 URL；保留安全文本、图片状态、按需加载和凭据隔离要求。

### 4.3 实现原则与验证门槛

缩略图用 `el-image`，预览采用应用协调的独立 `el-image-viewer`。同一次打开不能既触发 `el-image` 内建预览又挂载另一预览实例。布局使用库栅格或少量 CSS Grid；组件库不等于自带满足本项目全部规则的图片网格。

连接层负责 owner/序号映射、历史与会话同步、关闭来源判定、焦点/滚动协作，以及移动端滑动切图、双指缩放与双击缩放/还原的薄手势层；不重写库的图片缩放、旋转与拖动引擎。不依赖库私有 DOM 或内部方法完成关键行为；唯一允许的库内部类覆盖是窄屏隐藏切图箭头与图标工具栏（用于让位于滑动手势），须在实现证据中登记并由自动化守护。

采用原生组件不自动扩大产品范围：若库提供下载、自动轮播、额外富文本链接或其他未确认能力，应通过公开配置/插槽禁用或不暴露；不借换库增加 SRS 排除的图片下载、自由画布缩放、回复图片或深色模式；移动端双指缩放当前图片按 FR-09 纳入。

实施先用受控样例验证下列门槛，再扩大页面重写：

| 验证 | 通过条件 |
| --- | --- |
| 手机长图与工具栏 | iPhone Safari 可读完整长图、操作切换/关闭；不以桌面模拟代替实际结果 |
| 历史衔接 | 打开只新增一条预览历史；切图不增历史；按钮关闭与后退不造成二次后退；前进、刷新及遗留 state 有正确结果 |
| 滚动与焦点 | 底层不滚动、不跳位，关闭回到触发处或合理后备；库与应用没有双重滚动锁/双重恢复 |
| 错误与图片组 | 成功/坏图/未上传混合组不串 owner、索引不漂移，仍可切换/关闭/局部重试 |
| 资源请求 | 冷缓存、可区分缩略/预览 URL 的夹具下检查 Network；打开一张不要求先下载整组原图，不因全量挂载触发不必要的整组下载 |
| 控件与视口 | 四种宽度无页面溢出，工具栏可达，主要触控区域约 44px，键盘与焦点约束可用 |

官方文档不能证明这些组合行为成立。资源验证同时覆盖生产缩略图/预览共用 URL 的情况，不能将缓存命中当作没有请求整组的证据，也不把“只能新增恰好一个请求”另定为产品需求。

若公开配置与薄连接层仍无法满足保留项，记录具体失败条件，暂停相关替换并重新讨论库或需求；不静默降低 NFR-03、不自动恢复整套自研预览、不引入第二套库。原型是后续实施验证，不在本次文档工作中执行。

## 5. 新版视觉基准

浅青背景、白色内容卡片、青蓝选中态、粉色作者信息及内容层级作为产品识别方向保留；阅读页面继续居中主栏、手机单列，管理页沿用同一体系。通过 Element Plus 主题变量统一颜色、字号、圆角、间距、焦点与状态表达；内容布局补少量 scoped CSS 或 CSS Modules，不建立平行的自制基础控件样式库。

旧参考图及 #35 的量测保留为历史设计来源，不再作为 Vue 新版像素级通过门槛。字体、具体宽度、头像尺寸和间距由新版设计确定，但不得突破 SRS 的可读性、6 行折叠、无溢出、触控和键盘要求。

用受控内容提供列表、详情/评论/回复、窄屏独立楼中楼页、图片预览、管理列表和单 UP 管理页的代表截图，覆盖四种约定宽度及关键空/错状态。记录构建版本、浏览器、视口、缩放、字体与内容条件；由用户确认后成为新版回归基准。未经确认的当前实现截图不能自证视觉通过；后续回归不得仅通过更新黄金图掩盖意外变化。

## 6. 测试迁移与验收

### 6.1 测试分层

- 纯 TypeScript 契约/规则测试：能复用则保留，先核实当前结果，再对新版重跑；不以历史数量代替场景覆盖。旧测试与代码冲突时按代码修正预期，不用旧测试反向定义迁移目标。
- Vue 模块与页面行为：使用 Vitest 与 Vue 行为测试工具，优先 `@testing-library/vue`，底层需要时使用 Vue Test Utils；实施时核实兼容组合。验证用户操作和可见结果，不机械翻译 React 内部状态断言。
- Playwright：保留 mock 阅读、生产归档、管理和静态交付的不同装配与证据。部分旧回复 E2E 仍断言累计追加和无目标前缀，已与当前组件测试/代码不一致；迁移其有效场景并按当前分页、路由、前缀重写断言，不机械复用旧按钮文案。优先角色/可访问名称；阅读锚点使用稳定业务标识，不绑定库私有 DOM。原 `data-reading-id` 可保留，若调整须同步覆盖相同定位能力。
- 旧像素断言：按已确认新版视觉规范有依据地替换。折叠行数、位置恢复、内容可达、焦点和触控面积等行为断言不能以换库为由删除。
- 真实设备：Linux Chrome 与 iPhone Safari 分别记录实际版本及结果；自动化、模拟和真机不相互替代。

### 6.2 需求追踪
