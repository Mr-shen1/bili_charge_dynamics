# 页面视觉参考与功能裁剪（含监控管理）

## 1. 使用方式与范围

以下两张图是用户2026-10-14后续提供的当前列表卡／详情参考，已从临时附件复制到文档资源目录，避免 `/tmp` 路径失效。它们及用户指定现有B站页面的授权量测优先于首轮旧图，详见第6节；旧图与首轮证据保留为历史。它们是布局、配色和样式的参考，不是本站实现截图、测试结果、生产数据集或完整功能清单。

用户已进一步确认：以这两张图为基准，对保留的列表、详情、评论与回复阅读区域进行一比一视觉复刻，不只采用相近配色或自行设计卡片。宽度比例、头像与文字排列、字号行高、间距、圆角、分隔、图标及图片容器都属于对齐范围。用户行为与验收仍以 [SRS](../product/SRS.md) 为准，原阅读功能和下列功能裁剪保留；一比一指保留阅读区域的视觉，不是恢复 B站整站功能；监控管理页也纳入同一视觉体系的完整改版，而非只沿用配色。不能把参考图中的账号、正文或图片硬编码成应用数据。实施由 [35：B站视觉复刻与监控管理统一改版](../../.scratch/backend-integration/issues/35-bilibili-visual-replica.md) 负责，不改写历史验收结论。

## 2. 列表参考

![B站动态列表的用户提供参考](../assets/ui-reference/current-35/dynamics-list.png)

采用的结构与视觉：

- 浅青色页面背景、白色内容卡片，以留白和浅色分隔表达层次。
- 顶部为可横向滑动的“全部动态 + UP 头像与昵称”选择条，青蓝色表达当前选中项。
- 卡片头部保留头像、作者昵称、时间及可用的充电标识；作者名称参考粉色样式。
- 正文与图片采用适合桌面和手机阅读的间距、字号、宽度与圆角。
- 评论气泡小图标和评论总数是进入评论区的入口，不是评论图片缩略图。

交互裁剪：

- `/` 展示全部已归档动态；选择 UP 后使用 `/ups/:upId` 查看该 UP 的归档，不启动全历史采集。
- 卡片主体点击进入 `/dynamics/:dynamicId` 顶部；完全移除原“查看详情”按钮。
- 点击评论气泡图标或数量进入同一动态详情并定位评论区，不新增独立“评论详情页”。
- 图片点击打开图片预览；文本选择、正文展开、内部操作不能因冒泡触发卡片导航。卡片入口需要可用的键盘语义。
- 顶部 UP 选择项可导航，内容中的头像和昵称仍只展示，不新增个人主页跳转。
- **不显示转发图标、转发数量或任何转发操作，不保留空占位。**

## 3. 详情与评论参考

![B站动态详情及评论的用户提供参考](../assets/ui-reference/current-35/dynamic-detail.png)

采用的结构与视觉：

- 顶部作者信息，下方为动态正文与图片；评论入口及数量连接到评论区域。
- 评论标题、总数以及“最热 / 最新”切换，参考截图的信息层级、颜色与间距。
- 一级评论包含作者、时间、正文及有序图片；UP 标识按该动态作者判断。
- 回复缩进、预览和展开入口体现楼中楼关系，不增加无限嵌套。
- 一级评论图片可点击预览，沿用动态图已有的切换、关闭、长图、手势和焦点恢复规则。
- 监控管理页按两图的视觉体系重做：居中主栏、浅青背景、白卡、头像／昵称头部、字号、间距、分隔及信息层级映射为 UP 身份、配置表单、指定目标、检查／同步状态和操作反馈；不是只换颜色。管理布局没有对应的参考截图，须记录规则映射与受控管理截图，不伪称 B站管理页像素复刻，也不引入 B站后台功能。原 UID／配置／启停／目标／删除／重读能力及真实状态保留；无鉴权风险由部署文档声明，页面不常驻风险提示。

## 4. 不因参考图而改变的行为

- 列表按发布时间倒序；“最热”为点赞数降序、发布时间降序、ID 字符串升序，不新增置顶优先级或热度算法。
- “最新”按发布时间倒序，回复按时间正序；分页数值继续为动态 10、一级评论 20、回复预览 3 后每批追加 10。
- 时间展示沿用北京时间绝对时间规则；不因截图中的“3天前”改为相对时间。来源编辑字段只有分钟精度时，不伪造秒级编辑精度。
- 详情动态正文保持完整展示，不因参考图中的“展开”改变原已确认规则；列表、一级评论和回复仍使用原文字折叠规则。
- 普通阅读返回恢复、预览历史、焦点、局部失败重试均保留；全部列表和各 UP 列表的快照及分页相互隔离。
- 正文受限时不妨碍实际可读取的评论；失败、真实空内容和无权限不能混为同一状态。
- 2026-10-14 用户预览后明确取消列表及详情正文下方的整块归档信息：移除该块中的编辑时间、来源／本地评论与回复统计、正文／媒体／评论归档状态，也不增加折叠入口或替代提示。这替代此前将该信息块作为阅读页次级信息保留的布局决定；接口数据及管理检查状态不变，发布时间、正文、图片及评论入口保留，独立的页面读取错误、逐图状态和评论／回复区域不在本次删除范围。

截图中的视频、转发动态、转发按钮、评论输入框、真实点赞、关注、排行榜、推荐、勋章付费业务等不自动进入范围。允许展示充电标识，但不提供价格、购买、解锁或会员权限系统。一级评论图片明确新增，楼中楼回复图片不额外扩展。

## 5. 视觉与功能验收

- 列表对照列表图，详情及评论对照详情图，按保留区域的一比一视觉基准逐项核对，不能仅以“配色类似”或功能测试通过代替视觉对齐。
- 实施前记录可比区域、截图来源条件、缩放、字体与布局量测；现有图片未记录 CSS 视口和设备像素比，不能直接把图片像素宽度当作 CSS 视口事实。来源条件不可确认时记录推定和限制，建立可复核的比较方式，不伪造来源证据。
- 使用受控内容截图及差异图；遮罩仅用于可变账号、正文、图片和计数等业务内容，不遮罩容器、间距、图标或布局偏差。保留的绝对时间、详情全文和归档状态等必要差异单独说明；不得以这些行为差异为由重新设计整套视觉。
- 按 SRS 的 360px、390px、768px、1280px 视口检查，UP 条可自身横向滚动，但整个页面不能因此横向溢出。
- 沿用 Linux Chrome 与 iPhone Safari 的正式兼容范围，设备实测与模拟器结果分开记录。
- 验证卡片、评论图标、图片预览、展开和文本选择之间没有误跳转；无“查看详情”按钮或转发遗留。
- 一级评论图片、全部 / 单 UP 切换及管理页属于新增验收范围，不能由旧前端验收记录直接推定通过。管理页需提交同风格的 UP 卡片／表单／目标／状态截图与四宽度／键盘／操作回归，不能仅以基础配色一致算作改版完成。
